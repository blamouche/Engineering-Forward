# Microsoft Scout: Always-On AI Agent for the Microsoft 365 Stack
**Source**: https://tldrnewsletter.com (TLDR AI, 2026-06-08)
**Date**: 2026-06-08
**Author**: TLDR AI
**Keywords**: microsoft, scout, ai-agent, m365, persistent-agent, automation

## Elevator pitch
Microsoft Scout is an always-on agent for Frontier program users that enhances automation across the Microsoft 365 stack, offering multi-step routines, local file integration, and support for both OpenAI and Anthropic models.

## Takeaways
- Scout is an always-on agent available to Microsoft Frontier program users, designed for persistent automation in the Microsoft 365 ecosystem
- Supports multi-step routines that chain operations across M365 applications, integrating with local files and system context
- Allows users to choose between OpenAI and Anthropic models, rather than being locked to a single provider
- Currently gated to Frontier program users, positioning Microsoft strategically in the persistent agents space against competitors
- Represents Microsoft's move from Copilot-as-assistant to Copilot-as-autonomous-agent, a significant shift in product philosophy

## Synthesis
Microsoft Scout represents the company's strategic entry into the persistent AI agent space. While Microsoft Copilot has existed as an AI assistant embedded across the M365 stack, Scout is a different category of product: an always-on agent that operates autonomously, executing multi-step routines without continuous human prompting. This is available to Frontier program users, Microsoft's early-access tier for new AI features.

The agent supports multi-step routines that chain operations across Microsoft 365 applications — a user can define a workflow that reads an email, extracts data, updates a spreadsheet, and sends a Teams notification, all orchestrated by Scout. Local file integration means the agent can access and modify files on the user's machine, not just cloud-stored documents. The support for both OpenAI and Anthropic models is notable: it gives users a choice of underlying model rather than locking them into Microsoft's own OpenAI partnership.

Scout is currently gated to Frontier program users, which positions it as an experimental feature rather than a general release. This gating serves both as a risk management measure — persistent autonomous agents can cause significant damage if they make wrong decisions — and as a competitive positioning move against other companies building persistent agents. The product signals Microsoft's shift from "Copilot as assistant that responds to prompts" to "Copilot as autonomous agent that runs routines," which is a meaningful architectural and philosophical change.
