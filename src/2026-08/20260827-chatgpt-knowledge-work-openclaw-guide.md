# Our ChatGPT and OpenClaw Guides Just Got an Overhaul
**Source**: https://every.to/chatgpt-for-knowledge-work
**Date**: 2026-08-27
**Author**: Every (Katie Parrott)
**Keywords**: ChatGPT, OpenClaw, knowledge work, AI agents, ChatGPT Work, Codex, agent maintenance, personal agents, shared agents

## Elevator pitch
Every's updated guides reflect a maturing understanding of AI tools: ChatGPT now has a dedicated home for knowledge work (Work), and personal agents like OpenClaw carry a maintenance burden that grows with scale—leading to a shift toward shared company agents.

## Takeaways
- ChatGPT now has three modes: Chat for quick questions, Work for longer assignments, and Codex for software jobs—Work handles the vast majority of non-coding knowledge worker tasks
- New ChatGPT features: Goals (/goal for persistent objectives with definition of done), Projects (cloud vs local folder access), Scheduled Tasks, and built-in browser with Chrome profile support
- OpenClaw's appeal remains for individuals with recurring, personal work—but the maintenance burden of keeping credentials, integrations, and memory current is real and grows with team size
- A stronger model cannot log in when a credential expires, notice a broken integration, or detect stale instructions—human maintenance is still required
- Every is shifting to a shared Slack-based agent model (Every Agent) where one agent serves the whole company but each person works through their own connections and context
- The infrastructure around models—apps, tools, instructions, maintenance—can change results as much as a new model, sometimes more

## Synthesis
Every rewrote two of their AI guides this week, reflecting how the tooling landscape has matured. The ChatGPT for Knowledge Work guide (formerly Codex for Knowledge Work) has been recast around OpenAI's new Work mode. The key insight is that knowledge workers who don't touch code now have a dedicated interface: Chat stays for quick questions, Work handles longer assignments with file access and scheduled tasks, and Codex remains for software engineering. The guide retains its 16 workflows but recasts them for Work, covering new features including Goals (persistent objectives with a definition of done), Projects (choosing between cloud conversations and local folder access), Scheduled Tasks for recurring jobs, and a built-in browser that can use Chrome profiles for tasks needing existing sessions.

The OpenClaw guide update is more candid about limitations. A personal agent living in your messaging app, connecting to tools you authorize, and running recurring jobs without fresh prompts is appealing—but the maintenance burden is the hidden cost. Credentials expire, integrations break, memory fills with stale instructions. Putting the agent on a server keeps it running but doesn't eliminate the maintenance: somebody still has to keep tools connected, permissions current, and memory clean. This burden grows linearly with team size, which is why Every is pivoting toward a shared agent model—the Every Agent lives in Slack, serves the whole company, but each person works through their own connections and context.

The broader observation is that AI progress is not just about model capabilities. The infrastructure around the model—the app interface, file access, tool connections, saved instructions, and ongoing maintenance—can change results as much as a new model release. These guides are written to be useful for both humans and agents, suggesting users share them with their AI assistants and ask what lessons can be adapted to their own workflows.
