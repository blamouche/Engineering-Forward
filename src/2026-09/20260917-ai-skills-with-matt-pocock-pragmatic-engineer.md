# AI Skills with Matt Pocock
**Source**: The Pragmatic Engineer (pragmaticengineer@substack.com) — https://newsletter.pragmaticengineer.com/p/ai-skills-with-matt-pocock
**Date**: 2026-09-17
**Author**: Gergely Orosz (The Pragmatic Engineer)
**Keywords**: Matt Pocock, AI skills, grill-me skill, strategic programming, tracer bullets, memento-driven development, cloud agents, TDD, Total TypeScript, AI Hero

## Elevator pitch
A Pragmatic Engineer podcast episode with Matt Pocock — creator of the widely-used "grill-me" skill and the Total TypeScript course — covering his unconventional path from voice teacher to developer, how "leading words" from classic software engineering books make agents produce better code, and why you should optimize your codebase for a colleague who wakes up with no memory every morning.

## Takeaways
- **The "grill-me" skill was inspired by Anthropic's Thariq Shihipar**: The skill is surprisingly simple and short: it instructs an agent to interview the user relentlessly. Shihipar shared his approach of an agent interviewing its user about a topic and how it was surprisingly useful, and Pocock built a skill around the concept.
- **"Strategic programming" is the future of dev work**: Borrowing from John Ousterhout's "tactical programming" vs "strategic programming" categorization, Pocock believes agents are more than capable of tactical programming, leaving engineers to spend more time at the strategic level — planning, designing, and course-correcting rather than writing line-by-line code.
- **"Leading words" from classic books make agents produce better results**: Pocock noticed agents try to build software layer by layer, causing bugs between layers. Reading The Pragmatic Programmer, he discovered the concept of "tracer bullets." When he instructed the agent to use "tracer bullets" (implement a "golden path"), the agent started producing better code. He now reads classic software engineering books to discover other "leading words" that guide agents efficiently.
- **Memento-driven development**: "Imagine you have a human who wakes up every morning and cannot remember who they are, like the guy from Memento. We are trying to optimize our codebases for new starters, so we want the healthiest codebase we've ever had. A human can work around a bad codebase and develop a memory about it, but an agent can't — it starts afresh every session. So you need to optimize your codebase for that agent. And it turns out that software fundamentals have been trying to do that for the entire time."
- **Cloud-based agent setups beat local**: Pocock is moving his coding sessions to cloud agents because they run when he closes his laptop and can be made "multiplayer" (collaborative) in ways local agents cannot.
- **Mixed feelings on TDD with agents**: TDD helps developers with shorter working memories — a failing test reminds a distracted human what's broken. But agents have longer context windows, so Pocock asks agents to produce proof that their code works, with or without TDD.

## Synthesis
The Pragmatic Engineer's conversation with Matt Pocock covers his unconventional path from voice teacher to developer and AI skills creator. Pocock taught himself JavaScript to build a web audio spectrogram analyzer for singing students while teaching singing, accents, and Shakespeare at drama schools. He ran his own company at university, studied for a Master's in voice, and coached consulting firms on public speaking. When he received a full-time job offer from Vercel, he negotiated to work three days per week as a contractor so he could develop his TypeScript course on the other days. When Total TypeScript took off — generating more than $2.5 million in total sales — he quit Vercel to focus entirely on educational projects. His latest course is AI Hero.

The conversation explores Pocock's approach to working with AI coding agents. His "grill-me" skill, inspired by Anthropic's Thariq Shihipar, instructs an agent to interview the user relentlessly about a topic — a surprisingly useful technique for clarifying vague requirements. He describes a "day shift" and "night shift" approach to splitting context, keeping agents in their "smart zone" rather than their "dumb zone" where they produce lower-quality output. His "wayfinder" skill helps agents plan and course-correct.

The most actionable insight is the concept of "leading words." Pocock noticed that agents try to build software layer by layer, which causes bugs between the layers. Reading The Pragmatic Programmer, he discovered the concept of "tracer bullets" — a technique for implementing a "golden path" through a system. When he instructed the agent to use "tracer bullets," the agent started producing better code. He has since started reading classic software engineering books to discover other "leading words" — concepts from Domain-Driven Design, A Philosophy of Software Design, and other foundational texts — that guide agents efficiently. This bridges the gap between classic software engineering wisdom and modern AI-assisted development.

Pocock's "memento-driven development" concept reframes code quality as an agent optimization problem. Since agents start fresh every session without memory, codebases need to be healthier than ever — optimized for readability and understandability by someone seeing the code for the first time. The insight is that software fundamentals have been trying to achieve this for decades: clean code, clear naming, good architecture. The agent just makes the cost of bad fundamentals more visible. He is moving his coding sessions to cloud agents for the productivity benefits (they run when his laptop is closed, and can be made collaborative), and has mixed feelings on TDD with agents — believing agents can produce proof their code works without necessarily following strict test-first methodology.
