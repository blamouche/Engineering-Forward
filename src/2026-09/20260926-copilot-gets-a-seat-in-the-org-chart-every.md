# Copilot Gets a Seat in the Org Chart
**Source**: Every (hello@every.to)
**Date**: 2026-09-25
**Author**: Ryan Sloan (Every)
**Keywords**: Microsoft, Copilot, Autopilot, agents, org chart, evals, Satya Nadella, Charles Lamanna, enterprise AI, governance, permissions

## Elevator pitch
Microsoft announced a new unified Copilot app that combines chat, code, Office, and a persistent autonomous agent called Autopilot, replacing its separate consumer and work chat apps. Autopilot agents fit into an organization's governance structure with their own permissions and are shown "reporting" to their owners in the org chart — Microsoft's bet that workplace agents can be useful at scale if they inherit enterprise permissions and are held to company-specific evals.

## Takeaways
- **Unified Copilot app**: Three tabs — Home (chat + Office integration), Code (non-developer app building in secure environments), and Autopilot (persistent background agent you give a goal and set to work).
- **Autopilot as persistent agent**: Draws on 30 days of user work, org chart position, and calendar. Runs "Routines" like daily briefings or standing project watches. Charles Lamanna's Autopilot "Apollo" has the same Outlook access as his executive assistant.
- **Org chart integration**: Autopilot agents have their own permissions and report to their owners in the org chart, making AI agents identifiable and governable within enterprise structures.
- **Evals as the higher bar**: Microsoft runs ~16,000 internal evals. Nadella called for "evals specific to your company" — general benchmarks can't tell an organization whether an agent improves its own processes. Customers who succeed have the person doing the job build the eval, "embrace the red" (failing tests show what to fix), and measure human baselines first.
- **IT permissions double-edged sword**: The controls that make Copilot trustworthy (enterprise IT permissions) can also prevent it from completing tasks — a demo handoff from Chat to Code failed due to permission restrictions.
- **Usage-based credits**: Autopilot is off by default and runs on usage-based credits, reflecting the cost of always-on agent work.

## Synthesis
Microsoft's new Copilot represents a significant architectural bet: that the enterprise AI app wins not by having the smartest model, but by already owning the documents, conversations, and permissions that a workplace agent needs. The three-tab structure (Home, Code, Autopilot) addresses distinct use cases — context-aware Office work, secure no-code app sharing, and persistent background agents — while the org chart integration makes autonomous agents governable in a way that ungoverned tools like ChatGPT can't match. The emphasis on company-specific evals (16,000 internal at Microsoft) signals the industry's shift from benchmark-chasing to measuring real workflow improvement. However, the demo failures reveal the core tension: the same IT controls that make Copilot enterprise-safe can stop it from doing the cross-app handoffs that make the "one app" pitch compelling. Whether Microsoft can thread this needle — making permissions permissive enough for useful work but restrictive enough for compliance — will determine if workplace agents finally move from novelty to infrastructure.
