# Codex in Practice: Four Workflows for Getting the Most Out of Codex

**Date**: 2026-07-01
**Author**: Laura Entis / Every
**Keywords**: Codex, OpenAI, agentic workspace, Claude Code, AI workflows, Dan Shipper, Natalia Quintero, Kieran Klaassen, Katie Parrott, Austin Tedesco

## Elevator pitch
Every's team shares four distinct workflows for using OpenAI's Codex agentic workspace—from a lower-friction Claude Code alternative to a portable, cross-device AI system—demonstrating how different roles benefit from different Codex setups.

## Takeaways
- Codex is a versatile agentic workspace that adapts to how you work, but its flexibility makes onboarding overwhelming—there's no single "right way" to use it
- Natalia Quintero (Head of Consulting) uses Codex as a lower-friction Claude Code, letting it auto-build folder structures and file systems instead of manually architecting them
- Dan Shipper (CEO) organizes around long-running threads that retain full workflow history, plus an in-app browser for live context, and a router thread that delegates incoming requests to specialized sub-threads
- Katie Parrott (Staff Writer) uses a local "Katie Context" folder with AGENTS.md, identity file, preferences, anti-patterns list, project map, and voice file—built by Codex interviewing her about her role
- Austin Tedesco (Head of Growth) uses an outcomes-first approach: give Codex a result to produce, connect it to sources, and let it work autonomously with minimal structure
- Kieran Klaassen (Cora GM) treats Codex as one tool in a portable system: a synced folder across devices that any agent (Codex, Claude Code, Claude Cowork) can access, with automated daily/weekly/monthly memory summaries

## Synthesis
Every's "Codex in Practice" is a practical, use-case-driven guide to OpenAI's Codex agentic workspace, structured around how four different team members actually use the tool in their daily work. The article's core insight is that Codex's flexibility—its ability to adapt to any workflow—is both its greatest strength and its biggest onboarding challenge. There are no established best practices because what works depends entirely on your role, preferences, and the type of work you do.

Natalia Quintero's workflow demonstrates Codex as a lower-friction alternative to Claude Code. She previously spent significant time creating folder structures and file systems in Claude Code; with Codex, the app builds these for her as they work together. She opens the Codex project she's prioritized for the day and works from there, trusting Codex to make good decisions. She uses it for everything from achieving inbox zero to managing her father's healthcare—Codex serves as a central place to track medical appointments, follow-up protocols, and information from healthcare providers and family members.

Dan Shipper's approach is built on two components: long-running Codex threads that retain full workflow history (for recurring tasks like email processing, Slack/meeting transcript review, and hiring), and Codex's in-app browser that lets him and the agent use websites together. He also built a router thread with a dedicated email address (using a tool called Mailroom) that checks the inbox every few minutes, reads each request, and delegates it to the appropriate specialized thread.

Katie Parrott's setup is a structured local context folder called "Katie Context" with specific files: AGENTS.md (table of contents), an identity file, preferences for output production, a list of "don't do this" instructions, a project map, and a Voice.md file for writing style. She also uses Codex to maintain an "idea farm" for her biweekly column, with a rubric for evaluating ideas, scoring, and editorial notes.

Austin Tedesco's outcomes-based approach is intentionally lightweight. He gives Codex an outcome, connects it to sources, and lets it work. When output is bad, he asks Codex to audit where it went wrong and improve the setup. Kieran Klaassen's portable setup treats Codex as one tool in a larger system: a synced folder across all devices that any agent can access, with automated workflows that classify and extract key details from meeting transcripts, voice notes, and recordings, creating daily/weekly/monthly summaries that serve as reusable memory.

The article includes starter prompts for each approach, making it actionable for readers who want to adopt one of these workflows. The broader lesson is that the best way to start with Codex is to pick a setup that matches your working style and dive in rather than overthinking the architecture.
