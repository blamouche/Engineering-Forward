# Meta Build for Wearables: Web Apps for Ray-Ban Display
**Source**: https://wearables.developer.meta.com/docs/develop/webapps/build/
**Date**: 2026-07-02
**Author**: Meta
**Keywords**: Meta, Ray-Ban Display, web apps, wearables, AR development, Replit, Claude Code, Cursor, AI coding tools

## Elevator pitch
Meta launched a developer platform for building web apps on Ray-Ban Display smart glasses, using standard web APIs and AI coding tools like Replit, Claude Code, and Cursor to make development accessible.

## Takeaways
- Web Apps for Meta Ray-Ban Display use standard web APIs, making development accessible to web developers without specialized AR knowledge
- The easiest way to build these web apps is using AI coding tools and platforms such as Replit, Claude Code, and Cursor
- Meta is positioning its Ray-Ban Display as a developer platform, not just a consumer device
- The use of standard web APIs significantly lowers the barrier to entry compared to proprietary AR SDKs
- AI coding tools are explicitly recommended by Meta as the primary development approach, signaling mainstream adoption of AI-assisted development for new platforms

## Synthesis
Meta's "Build for Wearables" guide represents a significant strategic move: opening the Ray-Ban Display smart glasses as a developer platform using standard web technologies. Rather than requiring developers to learn a proprietary AR SDK, Meta has chosen to support standard web APIs, dramatically lowering the barrier to entry for the millions of web developers worldwide.

The decision to explicitly recommend AI coding tools—Replit, Claude Code, and Cursor—as the easiest development path is notable. It signals that Meta views AI-assisted development not as an optional enhancement but as the primary approach for building on this new platform. This is a strong endorsement of AI coding tools from one of the world's largest technology companies, and it positions these tools as the standard way to build for emerging hardware platforms.

The strategic implications are significant. By using web APIs, Meta ensures that any web developer can build for Ray-Ban Display without additional training. By recommending AI coding tools, Meta reduces the development effort further—developers can describe what they want in natural language and let the AI tool handle the implementation details. This combination could accelerate the creation of a Ray-Ban Display app ecosystem more rapidly than if Meta had chosen a proprietary development approach.

For the AI engineering community, this is further evidence that AI coding tools are becoming the default interface for building on new platforms. The fact that a platform launch explicitly recommends AI-assisted development over traditional hand-coding suggests the tools have reached a maturity level where they are trusted for production development on new, untested platforms.
