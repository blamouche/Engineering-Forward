# OpenAI's Plans For Its New ChatGPT Superapp
**Source**: https://www.bigtechnology.com/p/openais-plans-for-its-new-chatgpt
**Date**: 2026-07-10
**Author**: Alex Kantrowitz
**Keywords**: openai, chatgpt, superapp, codex, work-mode, agents, anthropic, product-strategy

## Elevator pitch
OpenAI's ChatGPT Superapp unifies coding, browsing, and AI work in a single desktop application, with a Codex/Work toggle and an intentional design choice to not over-refuse agent actions—a direct competitive move against Anthropic's Claude Cowork.

## Takeaways
- OpenAI finally shipped its "superapp," combining ChatGPT, Codex (coding), and internet browsing into one app with a new ChatGPT Work mode akin to Anthropic's Claude Cowork
- The Codex/Work toggle doesn't limit capability—only the UX around it; Codex surfaces code directly, Work mode presents results more casually
- A deliberate product philosophy: don't over-refuse. Where other AI agents decline to take actions (e.g., booking with a credit card), OpenAI's Work mode asks for permission but doesn't block by default
- OpenAI is careful with memory usage in the new app—while it has years of chat logs, it won't proactively rely on them unless the user explicitly asks, balancing personalization with privacy
- On competing with Anthropic (who arrived at this vision earlier with Claude Code and Cowork), lead Andrew Ambrosino says "going first has its weaknesses sometimes"—OpenAI has observed what works and is now executing on it

## Synthesis
OpenAI's long-promised ChatGPT Superapp represents a fundamental shift from chatbot to agent. Andrew Ambrosino, lead for Codex and the ChatGPT app, described it as "the start of the superapp—anything you can do on a computer, you can now do with this app." Users are already editing videos, creating Word docs, spreadsheets, slide decks, and even writing production-grade code within it.

The product's architecture centers on a toggle between Codex (code-intensive) and Work (less-technical) modes. This isn't a capability limitation—it's a UX choice. As Ambrosino explained, many use cases don't require digging into code, and the product can't always infer intent automatically. The Work mode presents results conversationally while Codex shows the underlying code.

A standout design principle is the intentional avoidance of over-refusal. Many AI agents default to saying no to potentially risky actions. OpenAI's approach: ask for permission, but don't block. "A lot of these general knowledge work modes nerf things that coding can just do," Ambrosino noted. "That's something we're trying to avoid."

Memory handling reveals a careful strategy. OpenAI has years of conversational data that could make the app deeply personalized, but the company chose not to lean heavily into this by default. If users explicitly ask the app to use what it knows about them, it will—but it won't do so proactively. This balances the obvious personalization advantage against privacy concerns and the risk of hallucinated preferences.

The competitive dynamic with Anthropic is central. Anthropic shipped Claude Code and Cowork first, establishing the "agent that does work" paradigm. Ambrosino's counter: "Going first has its weaknesses sometimes. We have seen how this stuff should work, and now we can go execute on it." This positions OpenAI not as a pioneer but as a fast follower with distribution advantages—ChatGPT's 900M+ weekly users give it a massive on-ramp to the agent paradigm that Anthropic can't match.
