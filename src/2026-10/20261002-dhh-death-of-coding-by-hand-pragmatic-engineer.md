# DHH Sparks New "Death of Coding by Hand" Debate
**Source**: The Pragmatic Engineer (pragmaticengineer+the-pulse@substack.com)
**Date**: 2026-10-01
**Author**: Gergely Orosz
**Keywords**: DHH, David Heinemeier Hansson, Ruby on Rails, 37signals, coding by hand, AI agents, Opus 4.5, software craft, abstractions, code quality, Rust, native mobile, software engineering

## Elevator pitch
Ruby on Rails creator DHH declared at Rails World that "coding by hand is dead" at 37signals — comparing AI's impact to the camera's effect on painting — and announced he has retired from being a professional programmer, sparking a heated debate across the dev community about quality, accountability, and what software engineering becomes next.

## Takeaways
- DHH: "At 37signals, a couple of weeks ago, we made the decision that it clearly means we're done writing code by hand... Writing code by hand is now an exceptional state, like seeing a bug in Sentry"
- November 24, 2025 (Opus 4.5 release) called the "Kodak Brownie moment" — the inflection point for the age of agents
- 37signals shifts: embracing native mobile apps (not web), moving backend services to Rust (agents write good enough Rust), keeping Ruby on Rails for web apps because convention-over-configuration suits agents
- DHH: "I have retired from being a professional programmer... Writing code by hand is no longer an economically productive enterprise for the vast majority of programmers"
- On abstractions: "the price of repetition has gone to near zero" — traditional abstraction patterns may need rethinking in the age of agents
- Anonymous Big Tech engineer rant went viral: "The state of engineering is horrible... Nobody is reading anything. Humans in corporate are doing nothing on their own... It is so soul-sucking"
- Software quality declining: Uber Eats shipped a feature with three obvious bugs (overflow, functional issues, "choose up to 999"), Spotify had unexplainable outages
- Predictions from January 2026 issue coming true: sloppier code, junior engineers pushed to senior fast, explosion in code volume, tougher work-life balance
- Counterpoint: software engineering is more important than ever — understanding LLMs, building agentic "software factories," creating deterministic code from nondeterministic LLMs
- Non-engineers adopting agents: OpenAI's finance, recruitment, and legal units moved to Codex in June 2026; Craft Docs built their own AI harness for non-engineering work
- OpenAI's software factory and Ramp's Inspect internal coding harness as examples of new quality assurance systems for agentic code
