# Mistral Vibe 2.0
**Source**: https://mistral.ai/fr/news/mistral-vibe-2-0
**Date**: February 2026
**Author**: Mistral AI
**Keywords**: Coding Agent, CLI, Devstral 2, Vibe Coding, Subagents, Developer Tools

## Elevator pitch
Mistral releases Vibe 2.0, a major upgrade to their terminal-native coding agent powered by Devstral 2, featuring custom subagents, multi-choice clarifications, and slash-command skills.

## Takeaways
- Vibe 2.0 introduces custom subagents for specialized tasks (deploy scripts, PR reviews, test generation), invokable on demand
- Multi-choice clarifications prevent blind guessing: Vibe now prompts with options when intent is ambiguous before acting
- Slash-command skills load preconfigured workflows (deploying, linting, docs) and unified agent modes combine tools, permissions, and behaviors
- Available on Le Chat Pro ($14.99/month, 50% student discount) and Team ($24.99/seat/month) plans with PAYG for extra usage or BYOK
- Devstral 2 API pricing: $0.40/$2.00 per million tokens (full model) or $0.10/$0.30 (Small); free tier available on Experiment plan

## Synthesis
Mistral AI announces Vibe 2.0, describing it as "terminally online"—a play on both the terminal-native interface and the intense, always-connected nature of the tool. The update represents a significant evolution of their coding agent, now powered by the Devstral 2 model family.

The headline features address core workflow pain points. Custom subagents allow developers to build specialized agents for specific tasks—one for deployment scripts, another for PR reviews, a third for test generation—and invoke them contextually. This modular approach acknowledges that different coding tasks benefit from different configurations and behaviors.

Multi-choice clarifications tackle the frustrating experience of AI agents guessing wrong. Rather than making assumptions when intent is unclear, Vibe 2.0 prompts users with explicit options before proceeding. This small change significantly reduces the back-and-forth of correcting misunderstood instructions.

Slash-command skills bring preconfigured workflows into the terminal. Common tasks like deploying, linting, or generating documentation can be triggered with a single command, loading the appropriate configuration automatically. Unified agent modes extend this further, allowing developers to define and switch between complete contexts—combining tools, permissions, and behaviors for different scenarios.

The pricing model balances accessibility with sustainability. Le Chat Pro at $14.99/month (with a 50% student discount) provides full access to the Vibe CLI and Devstral 2. Team plans add unified billing and priority support. Both tiers include generous base usage with pay-as-you-go at API rates when limits are exceeded.

Devstral 2 itself moves to paid API access, with the full model at $0.40 input / $2.00 output per million tokens, and a Small variant at $0.10/$0.30. Free API usage remains available on the Experiment plan for testing and prototyping.

For enterprises, Mistral offers fine-tuning on internal languages and DSLs, reinforcement learning with custom environments, and end-to-end code modernization services—capabilities they claim to already deliver for major organizations in finance, defense, and infrastructure. The announcement closes with a hiring push, signaling continued investment in AI developer tooling.
