# Microsoft tests Researcher and Analyst agents in Copilot
**Source**: https://www.testingcatalog.com/microsoft-tests-researcher-and-analyst-agents-in-copilot-tasks/
**Date**: 2026-02-16
**Author**: Alexey Shabanov
**Keywords**: copilot, agents, microsoft

## Elevator pitch
Microsoft is testing a unified Copilot “Tasks” feature that bundles Researcher and Analyst agents with scheduled prompts and a new Auto mode for end-to-end work.

## Takeaways
- Tasks unifies agentic features in Copilot with freeform and scheduled runs.
- Researcher and Analyst modes map to existing Microsoft 365 Copilot agents.
- A new Auto mode appears to combine deep research with browser control.
- Suggested prompts cover presentations, email summaries, bookings, and reports.
- The feature looks close but not fully finished, with no public launch date.

## Synthesis
TestingCatalog reports that Microsoft is developing a “Tasks” feature inside Copilot that consolidates several agentic capabilities into a single interface. The feature appears in recent Copilot builds alongside Projects, and offers two entry points: a freeform “New Task” and a “Scheduled Task” option that can run once or on daily, weekly, or monthly cadences. The emphasis is on creating a single, repeatable workflow surface for complex prompts rather than scattering these capabilities across separate tools.

A core element is the mode selector, which includes Auto, Researcher, and Analyst. Researcher and Analyst already exist as standalone agents in Microsoft 365 Copilot, released in mid‑2025. Researcher leverages OpenAI’s deep‑research model for multi-step investigations across web and work data, while Analyst uses the o3‑mini reasoning model to perform advanced data analysis with live Python execution. Bringing these into Tasks suggests Microsoft wants a unified entry point for higher‑end agent workflows.

The new Auto mode appears to be a general-purpose agent capable of running tasks end‑to‑end. It likely combines browser control (previously available as Copilot Actions) with deep research, hinting at an orchestration layer that can choose tools based on the task. This mirrors the direction OpenAI has taken with ChatGPT’s agentic features, but Microsoft adds scheduling, which could be a differentiator for productivity use cases where tasks need to run unattended.

Suggested prompts in the UI include generating presentations, summarizing emails, booking hotels, and writing formal letters. TestingCatalog’s experiments indicate output quality for slides and web-based reports is “notably high,” implying that Microsoft is improving presentation and reporting workflows for subscribers. The article speculates that Tasks could eventually extend across Windows and Edge, enabling OS‑level automation rather than limiting the agent to Copilot surfaces alone.

The feature is still in development. Some UI elements appear unfinished, and no official release date has been announced. However, the direction is consistent with Microsoft’s broader push toward more autonomous Copilot behavior in 2025–2026. If Tasks ships as described, it would give users a single place to launch, schedule, and manage complex agent workflows with different reasoning modes, marking a step toward fully automated productivity assistants.
