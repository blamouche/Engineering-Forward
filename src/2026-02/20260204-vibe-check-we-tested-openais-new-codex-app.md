## Elevator pitch
Every's team tests OpenAI's new Codex desktop app — a Mac GUI for coding agents that's the first interface to make some developers switch from terminal-based Claude Code, shifting the balance from 80/20 in Claude's favor to a 50-50 split.

## Takeaways
- The Codex app is a Mac desktop application providing a visual "command center for agents" that replaces the terminal UI for coding
- Dan Shipper went from 80% Claude Code / 20% Codex to a 50-50 split after weeks of testing
- The app features a sidebar for managing parallel agent threads, a chat interface, and inline code diffs

## Synthesis
Every's Vibe Check column delivers an early look at OpenAI's new Codex desktop application, a Mac app that positions itself as a "command center for agents" rather than a traditional IDE. The release represents OpenAI's direct response to Anthropic's Claude Code, which has dominated the coding agent space since its launch.

The app replaces the terminal-based interface most developers use to interact with coding agents. Its design features a left sidebar for managing multiple parallel agent threads across different workspaces, a center chat interface for real-time agent interaction, and an optional right sidebar showing code diffs in a format similar to Google Docs' suggestion mode.

The most striking finding from Every's testing is the shift in usage patterns. Dan Shipper, Every's CEO and an avid Claude Code user, reports moving from an 80/20 Claude Code/Codex split to 50-50 after weeks with the app. This is notable because many developers had dismissed graphical interfaces entirely after Claude Code made terminal-based coding feel superior.

However, the team's reactions are divided. Engineering lead Andrey Galko praises the cloud-to-local sync and clean UI, calling OpenAI "competitive" rather than playing catch-up. Naveen Naidu reports seeing his terminal usage drop significantly. But Kieran Klaassen, a die-hard Claude Code advocate, considers the return to a graphical interface a step backward, arguing that the future is more agentic and less human-controlled.

The broader significance is that OpenAI is commoditizing an entire ecosystem of startups building visual interfaces and workflow wrappers around coding agents. The app signals that the "terminal era" of coding agents may be brief, with GUIs making a comeback — not as the cluttered interfaces of old, but as purpose-built agent orchestration tools. Still, the article notes that Anthropic's combination of Claude Code, Cowork, and Opus 4.5 remains faster, more versatile, and better for a wider range of use cases overall.
