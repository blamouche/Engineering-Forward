# Code is Cheap. Show Me the Talk.
**Source**: https://nadh.in/blog/code-is-cheap/
**Date**: 2026
**Author**: Nadh
**Keywords**: LLM, Software Development, Vibe Coding, FOSS, AI-Assisted Coding, Code Quality

## Elevator pitch
Linus Torvalds' famous "Talk is cheap. Show me the code." has been inverted by LLMs—now articulation and engineering thinking matter more than typing code line by line.

## Takeaways
- Software development as practiced for decades is fundamentally over; LLM tools have compressed weeks of work into hours for experienced developers
- Traditional signals of code quality (documentation, comments, organization) are now meaningless since LLMs can generate them effortlessly
- The value of code now lies in accountability and human provenance, not just functionality
- FOSS dynamics are shifting as anyone can vibe-code custom solutions, threatening traditional collaboration incentives
- The real concern is a generation of developers who never develop fundamental skills because they rely entirely on AI assistants

## Synthesis
The essay opens by revisiting Linus Torvalds' 2000 quip about talk being cheap compared to code. For 25 years, software development required immense human effort—cognitive bandwidth, physical time, and the ability to hold complex systems in one's head while typing code line by line. Even with perfect knowledge of what to build, the act of writing quality code was expensive.

LLMs have completely inverted this dynamic. The author, a developer with 25 years of experience, describes regularly compressing months of work into days. When Torvalds himself merged AI-generated code into a project with the comment "Is this much better than I could do by hand? Sure is," the implications became undeniable.

The consequences ripple through every aspect of software. Traditional quality signals—clean documentation, thoughtful READMEs, well-organized code—no longer indicate human effort or expertise. LLMs can one-shot generate all of these, making it impossible to distinguish carefully crafted software from hastily vibe-coded projects without forensic analysis. The author suggests provenance and accountability are becoming more important than the code itself.

The essay tackles the FOSS ecosystem with particular concern. Open source collaboration emerged because software was expensive to create and required specialist skills. But when anyone can quickly generate custom solutions, what happens to the incentives for sharing? The author predicts that governance, curation, and trust will become more valuable than the code artifacts themselves.

Neither the manic vibe-coding evangelists nor the staunch AI denouncers have it right, the author argues. Both miss the pragmatic middle ground where experienced developers use these tools to achieve outcomes they couldn't reach before. The extreme vibe coders are creating a "Borgesian library" of infinite, valueless output, while denouncers can't acknowledge that many developers are getting genuinely useful results.

The deepest concern is generational. Experienced developers benefit enormously from AI assistance, but what about juniors who never develop foundational understanding? They become trapped in dependency on a "genie" they don't understand, unable to discern quality from slop. The author worries that seniors, empowered by AI, may feel less incentive to mentor—breaking a natural cycle of skill transmission that has defined the profession.

The conclusion is stark: "For the first time ever, good talk is exponentially more valuable than good code." The ability to imagine, articulate, and architect has become the bottleneck, not typing speed or syntax knowledge. This represents a fundamental disruption to software development roles, methodologies, and human collaboration dynamics.
