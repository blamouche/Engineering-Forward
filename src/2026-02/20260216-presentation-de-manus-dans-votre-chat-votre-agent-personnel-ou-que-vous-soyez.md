# Présentation de Manus dans votre chat : votre agent personnel, où que vous soyez
**Source**: https://manus.im/fr/blog/manus-agents-telegram
**Date**: 2026-02-16
**Author**: Manus
**Keywords**: ai, agents, messaging

## Elevator pitch
Manus introduces Manus Agents for Telegram, bringing its full multi-step agent capabilities into chat with fast setup, multimodal input, and task execution.

## Takeaways
- Manus Agents brings the full Manus agent into chat, starting with Telegram.
- Setup is QR-based and takes about a minute, no tokens or server config.
- Agents can run multi-step tasks and deliver results directly in the thread.
- The chat interface supports voice, images, and files with transcription and edits.
- Users can choose between Max and Lite models based on depth vs. speed.

## Synthesis
This announcement introduces Manus Agents, a new way to use Manus directly inside messaging apps, with Telegram as the first supported channel. The core promise is convenience: instead of configuring a separate tool or switching contexts, the agent lives in the chat interface where users already communicate. The post emphasizes that the Telegram integration is available for all users today, with other messaging platforms planned.

Manus positions this as a practical upgrade over earlier “agent in chat” attempts. Most existing solutions require complex setup, ongoing maintenance, or unpredictable costs, which limits adoption. Manus Agents aims to remove these barriers by making setup simple—open the Agents tab, connect, scan a QR code, and start chatting. The article stresses that there is no terminal usage, no configuration files, and no API tokens to manage.

The key capability is that this is not a lightweight chatbot wrapper. It is the full Manus agent with planning, tools, and multi-step execution, now reachable via a message. Users can launch end‑to‑end tasks like research, data processing, report generation, and PDF outputs, and have results delivered in the same chat thread. The agent orchestrates subtasks in the background and returns structured outputs without requiring the user to jump back to the web app.

The integration is multimodal. Users can send voice messages, photos, and documents; the agent transcribes audio, interprets intent, edits or transforms files, and responds with outputs directly in chat. The post also highlights personalization: users can specify a preferred response style—concise, structured, or conversational—and the agent will follow it across interactions.

Manus offers two model options within the chat interface. Manus 1.6 Max is positioned for deeper reasoning, multi‑step tasks, and creative work, while Manus 1.6 Lite prioritizes speed for everyday questions and summaries. Both models can complete full tasks, so the user chooses the trade‑off based on complexity and urgency.

The article includes concrete use cases. For weekly meeting preparation, a user can send a voice request to set up a recurring task that reviews email, summarizes upcoming meetings, and delivers the summary in chat. For creative profile images, users can submit a photo and request styled variations, which are generated and returned in the conversation. Another example shows turning a product photo and brief into a structured concept for a launch video, including scene ideas and visual direction. These examples reinforce the focus on end‑to‑end workflow outcomes rather than single-turn Q&A.

The FAQ addresses safety and scope. Manus says the agent only has access to the messages sent directly in the private chat; it cannot read other conversations or group chats. The post also confirms that multi-step tool use is supported and that additional messaging platforms are under active development.

Overall, the announcement frames Manus Agents as a shift in how personal AI is accessed: the agent should be available where the user already communicates, with low setup friction and full agent capabilities, not a constrained chat experience.
