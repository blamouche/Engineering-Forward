# What the Team Behind Cursor Knows About the Future of Code

**Source**: https://every.to/source-code/what-the-team-behind-cursor-knows-about-the-future-of-code

**Date**: January 22, 2026

**Author**: Katie Parrott

**Keywords**: Cursor, AI coding, IDE, software development, AI agents, model selection, developer workflows

## Elevator pitch

Cursor's team reveals that writing code manually now comprises as little as 10% of developer workflow time, with the focus shifting to managing AI agents and reviewing outputs rather than hands-on coding.

## Takeaways

- The traditional IDE is being replaced by agent-centric development where humans review AI-generated code rather than writing it
- Model selection for specific tasks matters more than traditional prompting techniques like adding incentives or special phrases
- Different models excel at different tasks: Claude Opus for conceptual problem-solving, GPT 5.2 Codex for thorough methodical work
- Cursor's research team built a functional web browser using AI agents running for weeks, generating 3 million lines of code at approximately $80,000 in token costs
- Design-to-code workflows from tools like Figma remain challenging and unreliable despite advances in other areas

## Synthesis

Every's Source Code column interviews members of Cursor's team to understand how professional developers are actually using AI coding tools. The opening claim from developer education lead Lee Robinson sets the tone: "The IDE is kind of dead." This provocative statement captures a genuine shift in how software development work is structured.

The most striking finding concerns time allocation. For some developers using Cursor, writing code manually now comprises as little as 10% of their workflow time. The remaining 90% involves managing AI agents and reviewing their outputs. This inversion fundamentally changes what it means to be a software developer, shifting the core competency from code production to code evaluation and agent orchestration.

Model selection emerges as a critical skill. Cursor engineer Samantha Whitmore describes personalized approaches for different models. Claude Opus excels at conceptual problem-solving and brainstorming, making it suitable for early-stage thinking and architectural decisions. GPT 5.2 Codex delivers thorough, methodical work but can fixate on single approaches, requiring intervention when it heads down unproductive paths. Engineers sometimes run parallel comparisons using up to eight models simultaneously, treating model diversity as a strategy for better outcomes.

Traditional prompting techniques have lost effectiveness. The article notes that tricks like "I'll pay you $1,000" for better outputs no longer work with current models. This suggests the models have matured past susceptibility to such heuristics, making genuine context and clear requirements more important than clever prompt construction.

Infrastructure capabilities demonstrate what extended agent autonomy enables. Cursor's research team built a functional web browser using AI agents running continuously for weeks. The project generated 3 million lines of code across thousands of files at approximately $80,000 in token costs. This example illustrates both the scale agents can achieve and the economics involved in ambitious autonomous projects.

Practical limitations persist despite the advances. Design-to-code workflows, particularly translating Figma designs into implementation, remain challenging and unreliable. Cost barriers also affect budget-conscious developers. Additionally, simpler straightforward tasks may not show time savings compared to manual work, suggesting AI coding tools provide disproportionate value for complex rather than routine tasks.
