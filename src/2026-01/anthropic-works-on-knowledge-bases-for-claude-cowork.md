# Anthropic Works on Knowledge Bases for Claude Cowork

**Source**: https://www.testingcatalog.com/anthropic-works-on-knowledge-bases-for-claude-cowork/

**Date**: January 18, 2026

**Author**: Alexey Shabanov

**Keywords**: Claude, Anthropic, knowledge bases, Cowork, productivity agent, MCP, Model Context Protocol

## Elevator pitch

Anthropic is developing persistent knowledge bases for Claude that the assistant can proactively reference and incrementally update, signaling a shift from chat assistant to comprehensive productivity agent.

## Takeaways

- Claude is gaining persistent knowledge repositories that it can proactively check for relevant context when answering questions
- Knowledge bases will be incrementally updated with preferences, decisions, and lessons learned during conversations
- Cowork is becoming Claude's primary mode, with traditional chat functionality folded into it as an optional mode
- The MCP (Model Context Protocol) registry is expanding for dynamic connector management
- Voice mode is being expanded to the web interface, alongside other multimodal improvements

## Synthesis

Anthropic is advancing Claude with several features that signal a strategic shift in how the company envisions AI assistants. The most significant development is the introduction of knowledge bases—persistent repositories that Claude can reference and update over time. According to internal instructions uncovered by TestingCatalog, Claude will proactively check these knowledge bases for relevant context when answering questions and add new information about user preferences, decisions, and lessons learned to appropriate bases.

This represents a fundamental change in how AI assistants maintain continuity. Current chat-based interactions are ephemeral by default, with each conversation starting fresh unless users explicitly provide context. Knowledge bases would allow Claude to build cumulative understanding of a user's work, preferences, and ongoing projects. The proactive aspect is particularly notable—rather than waiting for users to surface relevant information, Claude would actively consult its knowledge stores to inform responses.

The interface restructuring accompanying this feature reveals Anthropic's broader strategic direction. Cowork is becoming Claude's primary mode, consolidating what was previously separate chat functionality. Users who want simple conversational interactions can enable chat mode within Cowork rather than accessing an independent chat interface. A dedicated Artifacts section is being added to the right sidebar, making it easier to manage generated documents, code, and other outputs within a unified workspace.

Anthropic is also expanding the MCP (Model Context Protocol) registry for dynamic connector management. This enables Claude to integrate with external tools and data sources more flexibly, supporting the productivity agent vision by allowing users to connect their existing workflows and systems. Voice mode expansion to the web interface adds another input modality, making Claude more accessible across different work contexts and preferences.

A smaller but interesting addition is the refined Pixelate feature for generating pixel-art avatars with improved quality. While less consequential than knowledge bases, it demonstrates continued investment in Claude's creative capabilities alongside productivity features.

These updates collectively reflect Anthropic's mission to evolve Claude from a standard chat assistant into a comprehensive productivity agent. The emphasis on modular knowledge organization suggests a future where Claude serves as an intelligent layer across a user's entire work life, maintaining context across projects and time. The consolidation into Cowork as the primary interface underscores this vision—productivity and task completion are the central use case, with casual chat becoming secondary. The combination of persistent memory, external tool integration, and multimodal input creates a foundation for more autonomous and contextually aware AI assistance.
