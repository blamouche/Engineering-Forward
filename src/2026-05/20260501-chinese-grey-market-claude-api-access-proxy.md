# Chinese Grey Market Sells Claude API Access at 90% Off Through Proxy Networks That Harvest User Data
**Source**: https://www.tomshardware.com/tech-industry/artificial-intelligence/chinese-grey-market-sells-claude-api-access-at-90-percent-off-through-proxy-networks-that-harvest-user-data
**Date**: May 2026
**Author**: Tom's Hardware
**Keywords**: Claude API, grey market, proxy networks, data harvesting, model substitution, stolen credentials, China

## Elevator pitch
A Chinese grey market has emerged selling unauthorized Claude API access at 90% discounts through proxy networks that use stolen credentials, substitute models, and harvest users' prompts and outputs for resale as AI training data.

## Takeaways
- Chinese-operated "transfer stations" offer Claude API access at up to 90% below official pricing through proxy networks
- The grey market operates via stolen credentials and model substitution — users may not actually receive Claude responses but cheaper model outputs instead
- Users' prompts and outputs are harvested and resold as AI training data, creating a double exploitation model
- The operation exploits the gap between US export controls limiting official Claude/Anthropic API access in China and Chinese demand for frontier AI models
- This represents a new vector for model security: not just protecting the model weights but preventing unauthorized API access and data exfiltration through proxy networks
- The model substitution approach means users may be paying for Claude access but receiving responses from cheaper Chinese models — a quality risk compounded by data theft

## Synthesis
Tom's Hardware reports on the emergence of a sophisticated Chinese grey market for unauthorized Claude API access. Operating through proxy networks called "transfer stations," these operations sell API access to Anthropic's Claude models at discounts of up to 90% below official pricing, leveraging stolen credentials and model substitution techniques.

The operation works through several layers of exploitation. Users connect through a proxy network that routes their requests through compromised or unauthorized accounts. Rather than receiving guaranteed Claude responses, users may actually receive outputs from cheaper, substitute models — paying for Claude but getting something else entirely. Simultaneously, the operators harvest both user prompts and model outputs, repackaging them for resale as AI training data, creating a second revenue stream from stolen data.

The market exists because of the gap between US export controls that restrict official Claude API access in China and substantial Chinese demand for frontier AI models. For organizations and individuals in China who cannot access Claude through legitimate channels, these grey market services offer an appealing alternative — despite the obvious security and quality risks.

The vulnerability is not in Claude's model architecture but in the access layer. Stolen credentials, unsecured API keys, and proxy routing allow these services to function without needing to exfiltrate the underlying model weights. This represents a growing challenge for frontier AI companies: securing not just the models themselves but the entire access infrastructure. The dual exploitation — defrauding Anthropic of revenue while stealing user data for training — suggests a business model that may become increasingly common as the gap between AI haves and have-nots, defined by export controls and geopolitical restrictions, widens in 2026 and beyond.
