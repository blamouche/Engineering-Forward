# AI Work Is Splitting in Two
**Source**: https://every.to/context-window/ai-work-is-splitting-in-two
**Date**: May 10, 2026
**Author**: Every Staff (Context Window)
**Keywords**: AI agents, delegation, collaboration, Anthropic, OpenAI, Codex, Managed Agents, biotech, Code with Claude

## Elevator pitch
AI work is bifurcating into two distinct modes — delegation to long-running autonomous agents and real-time collaboration with AI — and knowing which mode fits each task is becoming the critical meta-skill for knowledge workers.

## Takeaways
- AI work is splitting into delegation (long-running agents like OpenClaw or Claude Managed Agents) and collaboration (desktop apps like Codex and Claude Code where humans and AI work side-by-side in real time).
- Anthropic's 2026 Code with Claude conference centered on Managed Agents with new features for spinning up, scaling, and managing cloud-based Claude instances that run 24/7.
- The "allocation economy" thesis — that the future is purely about delegating work to agents — only captures half the picture; collaborative AI work is equally important.
- OpenAI's GPT-5.5 launch and Anthropic's developer conference happened back-to-back, signaling intensifying competition in the agent platform space.
- Biotech R&D productivity is rising for the first time in years, driven by AI tools like AlphaFold and the collapse of genome sequencing costs to ~$200.
- Anthropic announced a partnership to use SpaceX's Colossus supercluster, signaling the infrastructure scale required for agent platforms.

## Synthesis
The Every team's Context Window newsletter crystallizes a pattern that has been emerging across the AI industry: AI work is splitting into two fundamentally different modes. The first is delegation — handing off work to long-running autonomous agents like OpenClaw, Claude Managed Agents, or Codex workflows that run independently. The second is collaboration — working alongside AI in real time through desktop apps like Codex and Claude Code, where humans provide judgment, context, and course correction as the AI operates.

This bifurcation became visible during a consequential week in early May 2026, when OpenAI held a "low-key" launch party for GPT-5.5 on May 5 at 5:55 p.m. (a time chosen by the model itself), and Anthropic held its second annual Code with Claude developer conference the following day. At Anthropic's event, the centerpiece was Managed Agents — Claude instances wrapped in cloud infrastructure that teams can spin up, scale, and manage, with the goal of letting users simply specify an outcome and a budget. Anthropic also announced a partnership with SpaceX's Colossus supercluster, underlining the massive compute infrastructure now required for agent platforms.

Dan Shipper's reporting from Code with Claude captures the strategic positioning: battle lines are being drawn on two fronts. Desktop apps compete for the collaboration use case, while managed agent platforms compete for delegation. This matches how agents have evolved inside Every itself — some are delegated to, others are collaborated with — and the pattern is showing up in how frontier labs embed employees in large enterprises.

The newsletter also highlights an important corrective to the "allocation economy" thesis. The idea that knowledge work would become purely about allocating tasks to agents was only half right. The other half is collaborative AI work, where humans and machines work together in real time, with the human providing context, taste, and judgment that agents still cannot replicate. The new meta-skill is discernment: knowing which tasks to delegate, which to collaborate on, and which to do yourself.

Beyond the agent theme, the newsletter includes a notable segment on biotech optimism. Biotech R&D productivity is rising for the first time in years, driven by two AI-enabled breakthroughs: AlphaFold mapping 200 million protein structures, and genome sequencing costs collapsing from $100 million in 2001 to roughly $200 today. These advances are narrowing the search space before experiments begin and enabling population-scale genetic analysis — transforming biotech from a money pit into something closer to the software investment model of low marginal cost and high value.
