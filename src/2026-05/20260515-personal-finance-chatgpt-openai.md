# A New Personal Finance Experience in ChatGPT

**Source:** [OpenAI Blog](https://openai.com/index/personal-finance-chatgpt) — May 15, 2026

## TL;DR
ChatGPT launches a personal finance experience (preview, Pro users, US only) that lets users connect financial accounts via Plaid. Combines GPT-5.5 Thinking's reasoning with real account data for personalized budgeting, spending analysis, goal planning, and scenario comparison. 200M+ users already ask ChatGPT finance questions monthly; now answers are grounded in actual financial context.

## Key Points

### How It Works
- Connect accounts via Plaid (12,000+ financial institutions supported); Intuit support coming soon
- Dashboard shows portfolio performance, spending, subscriptions, upcoming payments
- Users can share context (mortgage, savings goals, major purchases) saved as "financial memories"
- Default model: GPT-5.5 Thinking; GPT-5.5 Pro achieves best benchmark scores

### Use Cases
- Goal planning, travel spend analysis, spending insights, scenario planning, investment risks, subscription review
- Example: "Help me save more" → analyzes actual spending patterns, sets category-specific caps with dollar targets

### From Answers to Action
- Partnership with Intuit for next phase: credit card recommendations → approval odds → application; tax estimates → live expert sessions
- All within ChatGPT

### Privacy & Controls
- ChatGPT sees balances, transactions, investments, liabilities — NOT full account numbers or ability to make changes
- Model training settings respected; can disconnect accounts anytime (data deleted within 30 days)
- Financial memories can be viewed/deleted
- Temporary chats don't access connected accounts
- MFA recommended

### Quality Benchmark
- Internal benchmark developed with 50+ finance professionals
- GPT-5.5 Thinking: 79/100; GPT-5.5 Pro: 82.5/100
- Evaluates response quality holistically on complex personal finance tasks

## Relevance to Engineering-Forward
Represents the "connected AI" paradigm where LLMs integrate with real financial infrastructure. The Plaid partnership model (AI platform + financial data layer) signals how agent platforms will compose with specialized infrastructure providers.
