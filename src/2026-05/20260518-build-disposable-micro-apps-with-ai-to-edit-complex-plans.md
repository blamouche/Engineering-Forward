# Build Disposable Micro-Apps with AI to Edit Complex Plans

**Source:** [ChatPRD / AI Workflows](https://www.chatprd.ai/how-i-ai/workflows/build-disposable-micro-apps-with-ai-to-edit-complex-plans)
**Date:** 2026-05-18
**Level:** Intermediate | Engineering | Claude

## Summary

A workflow for editing complex rules or tables in AI-generated HTML plans: prompt Claude to build a temporary, custom user interface (a "micro-app") specifically for the editing task, use it, then discard it.

## Step-by-Step

1. **Identify an editing challenge** — find a complex section within your AI-generated HTML plan that's tedious to edit via text (e.g. a table of decision rules or configuration data)

2. **Prompt for a custom editing UI** — ask the AI to build a tool specifically for your problem:
   > "I want to create an edible HTML artifact to help me define the decision rules... I don't like the ones we have right now. Make this a custom UI that helps me with structure but gives me flexibility. Design the ideal interface for this problem."

3. **Use the throwaway micro-app** — interact with the generated custom webpage which provides a dedicated UI with input fields, buttons, and controls

4. **Integrate the refined output** — use built-in functionality (e.g. "copy to clipboard" button) to transfer the final structured output back into your main project

## Key Insight

This is "micro-software on top of micro-software" — with AI abundance, you can afford to generate throwaway tools that make your own process more efficient and enjoyable. Build the perfect tool for every specific problem, then discard it.
