# How I Use LLMs as a Staff Engineer in 2026

**Source:** [seangoedecke.com](https://www.seangoedecke.com/how-i-use-llms-in-2026/)
**Date:** 2026-05-17
**Author:** Sean Goedecke

## Summary

A follow-up to Goedecke's 2025 post on LLM usage, reflecting on how AI adoption has changed for a staff engineer over 15 months. The biggest shift: agents are now genuinely good, going from occasional suspicious use to constant light-supervision use.

## Key Takeaways

- **Agents produce entire PRs now** — every change starts with an agent attempt; often pushed after a single editing pass
- **Bug hunting is ~80% handled by agents** — but human expertise narrows the search space for the remaining 20%
- **Still no LLMs for writing** — PR descriptions, ADRs, messages, and blog posts are hand-written; LLMs used only for proofreading/feedback
- **Testing and setup offloaded to agents** — agents test changes, write unit tests, and handle local machine config issues
- **Core shift: from prompting to assigning** — agents recover from mistakes autonomously and work fast enough that watching them isn't productive

## Key Quote

> "The current core AI skill is shifting as much work onto AI agents as possible, without going too far."
