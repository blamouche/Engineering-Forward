# Microsoft's Developer Tools Roots
**Source**: https://newsletter.pragmaticengineer.com/p/microsofts-developer-tools-roots
**Date**: January 21, 2025
**Author**: Gergely Orosz
**Keywords**: Microsoft, developer tools, Visual Studio, MSDN, BASIC, TypeScript, GitHub, history

## Elevator pitch
Microsoft's quiet dominance in modern developer tools — VS Code, GitHub, TypeScript, npm — is not an accident but the result of 50 years of strategic investment in developer ecosystems, dating back to its origins as a BASIC interpreter company in 1975.

## Takeaways
- Microsoft started as a tools company (Altair BASIC, 1975), not an OS company — the developer tools DNA has been present since day one
- In the 1980s-90s, Microsoft built an ecosystem moat around Windows through compilers (Microsoft C, QuickC), an IDE (Visual Studio), a developer magazine (MSJ), and the MSDN paid documentation network
- Startups today largely reject the "Microsoft stack" (C#, .NET) but enthusiastically adopt Microsoft-owned tools (VS Code, GitHub, TypeScript, npm) — all part of the same strategy
- Microsoft likely loses money on GitHub Copilot at $10/month — the play is ecosystem lock-in, not per-unit profit
- No other Big Tech company invests as heavily in developer tooling, suggesting Microsoft has a unique strategic appreciation for developer ecosystem control

## Synthesis
Gergely Orosz examines a paradox of modern software development: most startups and scaleups would say they emphatically do not use the "Microsoft stack" — yet almost all of them use VS Code as their editor, GitHub for source control, TypeScript for frontend development, and npm for package management. All of these are Microsoft products. The apparent contradiction makes sense only when viewed through the lens of Microsoft's history as a developer tools company.

Microsoft's origin story is surprisingly misremembered. The company was founded in April 1975 to sell a BASIC interpreter for the Altair 8800. Bill Gates and Paul Allen built the interpreter in two months without even owning an Altair — Allen wrote a simulator based solely on Intel's 8080 manual while Gates coded the interpreter. Their first corporate contract was licensing "Altair BASIC," and the company then built Microsoft BASIC interpreters for Apple II, IBM, Commodore 64, and many others. The "Microsoft" brand appeared on startup screens, building name recognition among the nascent developer community.

Throughout the 1980s and 1990s, even as MS-DOS and Windows became Microsoft's commercial engines, the company kept investing in developer tools that made building for those platforms easier. QuickBasic, Microsoft C, QuickC, and the Microsoft Foundation Class Library (MFC) progressively lowered the barrier to Windows development while creating switching costs. CodeView introduced full-screen debugging — a genuine innovation at the time. The Microsoft Systems Journal, launched in 1986 as a printed magazine for developers, and MSDN, a paid documentation and software access network, created information moats around the ecosystem. The famous "Developers, developers, developers!" chant had real strategic context: Microsoft knew .NET adoption depended on developer enthusiasm.

The modern incarnation of this strategy is more subtle but equally deliberate. VS Code was built and given away for free, upselling services like Azure. GitHub was acquired for $7.5B in 2018 and has only grown. GitHub Copilot is likely sold at a loss at $10/month — a pricing strategy designed to build habits and ecosystem dependency rather than direct revenue. TypeScript and npm reinforce the web of tools that make Microsoft indispensable to developers regardless of what backend stack they use. No other Big Tech company (Google, Apple, Meta, Amazon) invests comparably in developer tooling, suggesting Microsoft alone retains the institutional understanding that controlling the developer tool layer means influencing what gets built, where it gets deployed, and who pays for the infrastructure. The strategy's success is evident in the fact that most developers don't even mentally categorize VS Code or GitHub as "Microsoft products" — the ultimate achievement of a platform play.
