# How to Build a Live, Auto-Updating Personal Dashboard with Claude
**Source**: https://www.chatprd.ai/how-i-ai/workflows/how-to-build-a-live-auto-updating-personal-dashboard-with-claude
**Date**: May 25, 2026
**Author**: ChatPRD (from Felix Rieseberg interview)
**Keywords**: Claude Cowork, Live Artifacts, dashboard, Connectors, Gmail, Spotify, Notion, Calendar, automation

## Elevator pitch
A step-by-step guide to creating a personal dashboard that auto-refreshes with live data from Spotify, Gmail, Calendar, and Notion using Claude's Live Artifacts and Connectors — create it once, and it stays relevant forever.

## Takeaways
- Set up Connectors in Claude settings to securely link Spotify, Gmail, Google Calendar, and Notion with OAuth-style sign-in, no API keys needed.
- Use an open-ended prompt with the key phrase "make this a live artifact" to enable auto-refreshing capability.
- Give Claude creative freedom: "whatever else you find that's relevant to my life" lets the model discover useful data sources.
- Live Artifacts are a creative canvas — Felix demonstrated redesigning the dashboard as "early 2000s software" with Winamp references and pixelated aesthetics.
- Once created, the dashboard refreshes with a single click, pulling the latest data from all connected services.

## Synthesis
This workflow guide captures the Live Artifacts feature's product philosophy: create once, stay relevant forever. The technical setup is minimal — OAuth-style Connectors replace API key management — and the prompt pattern is intentionally open-ended. The magic phrase "make this a live artifact" transforms a static output into a living document that refreshes against real data. The creative customization step (redesigning as early-2000s software) demonstrates that these aren't sterile corporate dashboards — they're personal tools with personality. The underlying pattern is powerful: instead of checking multiple apps daily, consolidate everything into a single, auto-refreshing view designed by — and for — you.
