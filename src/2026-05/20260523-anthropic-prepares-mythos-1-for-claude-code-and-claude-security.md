# Anthropic prepares Mythos 1 for Claude Code and Claude Security
**Source**: https://www.testingcatalog.com/anthropic-prepares-mythos-1-for-claude-code-and-claude-security/
**Date**: May 23, 2026
**Author**: Alexey Shabanov
**Keywords**: Anthropic, Mythos, Claude Code, cybersecurity, Claude Security, AI security, vulnerability discovery

## Elevator pitch
Leaked UI strings and a Project Glasswing update indicate Anthropic is preparing "Mythos 1" for integration into Claude Code and Claude Security, marking a shift from restricted access toward broader availability of its cybersecurity-focused AI model — alongside a new vulnerability dashboard and rumors of Claude Opus 4.8.

## Takeaways
- Project Glasswing, Anthropic's collaborative cybersecurity initiative, has found 10,000+ high- or critical-severity vulnerabilities since launch
- Anthropic's public messaging shifted from "Mythos will remain restricted" to "we look forward to making Mythos-class models available through a general release once safeguards are in place"
- UI leaks show a "claude-mythos-1-preview" model surfaced in Claude Code, with source code strings referencing "Access to the Claude Mythos model in Claude Code and Claude Security"
- Claude Security is getting a refreshed dashboard with vulnerability discovery charts, seven-day and thirty-day history views, and triage results
- Claude Opus 4.8 is rumored to be in internal evaluation with select partners, fitting the Opus 4.7 release cadence from April
- Mythos traces have already appeared on Google Cloud and AWS through existing vulnerability discovery programs

## Synthesis
Anthropic is preparing to operationalize its Mythos cybersecurity model beyond research, integrating it directly into developer and enterprise tools. The shift from Project Glasswing's collaborative vulnerability discovery to productized Mythos 1 in Claude Code represents a significant moment: what was positioned as a carefully restricted, high-risk model is now being readied for controlled but broader access.

The evidence comes from multiple sources. UI leaks showed "Mythos 1" temporarily visible in the model selector, and source code strings reference access to Mythos in both Claude Code and Claude Security. Anthropic's own messaging on May 22 acknowledged the transition: after finding over 10,000 high- or critical-severity vulnerabilities through Glasswing, the company stated it was working toward a general release of Mythos-class models — a notable departure from earlier language emphasizing permanent restriction.

The Claude Security dashboard refresh is the operational counterpart. Enterprise customers will get historical vulnerability charts and deeper triage results that bring the product closer to existing security scanner interfaces. If Mythos 1 delivers on the vulnerability-finding capabilities demonstrated through Project Glasswing, the combination could give Anthropic a differentiated enterprise security offering — AI-native vulnerability discovery integrated into the development workflow itself.

The timing aligns with the broader competitive landscape. Google recently open-sourced a security scanner (Bumblebee), and the open source supply chain is under unprecedented attack from groups like TeamPCP. By putting Mythos into the hands of developers through Claude Code and enterprise security teams through Claude Security, Anthropic is betting that AI-augmented vulnerability discovery becomes a market category, not just a research capability. The rumored Opus 4.8 release would complete a powerful narrative: better coding, better security, all from one provider.
