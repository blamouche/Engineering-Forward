# Domain Knowledge Is the Leverage

**Source:** https://log.beshr.com/domain-knowledge-is-the-leverage
**Date:** 2026-05-14

## Summary

Beshr Kayali Reinholdsson argues that as AI agents become increasingly capable at producing code, the value shift moves from code-writing to domain understanding. Key insights:

- Things that make code easier for humans (modular boundaries, clear interfaces, good tests, detailed domain language) are exactly what make code easier for agents
- Micro-level coding work (refactoring a single function) has lost leverage — an agent can produce a reasonable implementation faster
- The new high-leverage skill: understanding the domain and how it connects to the program, similar to the shift toward senior roles where you maintain the overall system shape
- Specs are valuable not as 10k-line documents but as captured decisions: interfaces, dependencies, constraints
- Tests matter more than ever — when agents generate code, you need verification that it did the right thing
- Everyone is experimenting; insights come from small experiments, not taking anyone's word for it (including AI's)
- The author links to his own experiment Ossature, where the spec is the source of truth and each task gets only needed context
