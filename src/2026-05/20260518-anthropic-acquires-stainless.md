# Anthropic acquires Stainless

**Source:** Anthropic (Official)
**Date:** May 18, 2026
**URL:** https://www.anthropic.com/news/anthropic-acquires-stainless

## Summary

Anthropic announced the acquisition of Stainless, the SDK and MCP server tooling company that has powered the generation of every official Anthropic SDK since the company's earliest API days. Stainless turns API specs into SDKs across TypeScript, Python, Go, Java, and more, plus CLIs and MCP servers. The acquisition aims to advance Claude's ability to connect to data and tools.

## Key Points

- **Stainless founded in 2022** by Alex Rattray; has powered Anthropic's SDKs since the beginning
- **What Stainless does:** Generates SDKs, CLIs, and MCP servers from API specs across multiple languages — "fast, reliable, and built to feel native in its language"
- **Strategic rationale:** "The frontier of AI is shifting from models that answer to agents that act — and agents are only as capable as the systems they can reach"
- **MCP connection:** Anthropic created MCP to make agent connectivity possible; Stainless accelerates this by making it easier for APIs to become MCP servers
- **Quotes:** Katelyn Lesse (Head of Platform Engineering): "Agents are only as useful as what they can connect to." Alex Rattray: "Anthropic was one of the first teams to bet on this with us"
- **Hundreds of companies** rely on Stainless for SDK generation
- **Team integration:** Stainless team joins Anthropic, continuing to work on developer experience and agent connectivity

## Why It Matters

This is a strategic infrastructure acquisition. Anthropic isn't buying a product to sell — it's buying the tooling layer that determines how easily any API becomes accessible to agents. As the industry shifts from model capabilities to agent connectivity (MCP ecosystem), owning the SDK-generation pipeline is a platform play that could give Claude a structural advantage in the "agents that act" era.
