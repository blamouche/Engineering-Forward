# Vercel Built a Programming Language for AI Agents

**Source:** [Unwind AI](https://www.theunwindai.com/p/vercel-built-a-programming-language-for-ai-agents/)
**Date:** 2026-05-18
**Authors:** Shubham Saboo, Gargi Gupta

## Summary

Vercel's Chris Tate created Zero, a new systems language where AI agents are first-class users of the entire toolchain. Compiler errors return structured JSON with stable error codes and fix suggestions agents can parse programmatically. Also covers: Garry Tan's open-source GBrain, LiteLLM agent sandboxes, Peter Steinberger's $1.3M monthly token spend, and Codex hitting 4M WAU on mobile.

## Key Takeaways — Zero Language

- **Agent-first compiler**: errors return JSON with stable codes, line locations, and repair metadata
- **Tiny native binaries**: no GC, event loop, or hidden runtime overhead — targets CLI tools and serverless
- **Full CLI toolchain**: check, build, run, test, format, inspect, dependency graphs, docs — all machine-readable
- **Apache 2.0 licensed** from Vercel Labs

## Other Highlights

- **GBrain (Garry Tan)**: structured knowledge brain with 17K+ pages, self-wiring graph, 34 skills, MECE organization
- **LiteLLM Agent Platform**: K8s sandboxes for agent fleets with credential vault — agents never see real API keys
- **Peter Steinberger's $1.3M token spend**: ~$20K/day on GPT-5.5 powering OpenClaw agents — token spend becomes infrastructure
- **Codex hits 4M WAU on mobile**: coding agent on iOS/Android via ChatGPT app
