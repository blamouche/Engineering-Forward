# Anthropic prepares Mythos 1 for Claude Code and Claude Security
**Source**: https://www.testingcatalog.com/anthropic-prepares-mythos-1-for-claude-code-and-claude-security/
**Date**: May 23, 2026
**Author**: Alexey Shabanov
**Keywords**: Anthropic, Claude, Mythos, cybersecurity, AI security, enterprise, Project Glasswing, Claude Code

## Elevator pitch
Anthropic is preparing Mythos 1 for broader release through Claude Code and Claude Security, signaling a shift from restricted access to general availability once adequate safeguards are in place, alongside a new enterprise vulnerability dashboard and rumors of Claude Opus 4.8.

## Takeaways
- Anthropic's Project Glasswing has found over 10,000 high- or critical-severity vulnerabilities in essential software since launch.
- The company now states Mythos-class models could reach general release once "far stronger safeguards" are developed, a shift from earlier restricted-access framing.
- Traces of "claude-mythos-1-preview" have surfaced on Google Cloud and AWS, with source code strings referencing access to "Claude Mythos model in Claude Code and Claude Security."
- A new Claude Security dashboard is being built with vulnerability discovery data, 7-day and 30-day historical charts, and deeper triage results for enterprise customers.
- Claude Opus 4.8 is rumored to be undergoing internal evaluations by select partners, with a potential launch in the coming weeks.

## Synthesis
Anthropic is taking concrete steps toward making its most advanced AI model, Claude Mythos, available beyond restricted programs. The company originally indicated Mythos would remain limited-access due to cybersecurity risks, but a May 22, 2026 Project Glasswing update reveals a strategic shift: once sufficient safeguards are in place, Mythos-class models will see a general release. This is significant because it suggests Anthropic believes it can adequately contain the risks posed by frontier-level AI capabilities.

The productization effort is visible in two parallel tracks. First, source code references show that "claude-mythos-1-preview" is being prepared specifically for Claude Code (developer tooling) and Claude Security (enterprise vulnerability management). Some users were even briefly able to see the "Mythos 1" model name in the UI, confirming active deployment work. Second, the Claude Security dashboard is receiving a structural overhaul, adding vulnerability discovery data, historical charts spanning seven and thirty days, and deeper triage results. While the product remains enterprise-focused for now, these refinements bring it closer to the maturity of rival security suites.

Project Glasswing has already demonstrated tangible results, with Anthropic and its partners discovering more than ten thousand high- or critical-severity vulnerabilities in essential software, including open-source projects. This operational success likely underpins the confidence to move toward broader Mythos access — the safeguards are being battle-tested in real-world security contexts rather than developed purely in theory.

Adding to the product momentum, Claude Opus 4.8 is reportedly undergoing internal evaluations by select Anthropic partners, with a potential launch in the coming weeks. This would follow the cadence set by Opus 4.7 in April and suggests Anthropic is executing on a faster release rhythm across its model lineup, from the frontier Mythos tier to the mainstream Opus family. The simultaneous advances in model capability, security infrastructure, and enterprise tooling paint a picture of a company preparing for the next phase of commercial AI deployment.
