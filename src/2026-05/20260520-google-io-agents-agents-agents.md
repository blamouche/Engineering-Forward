# Google I/O: Agents, Agents, Agents
**Source**: https://every.to/context-window/google-i-o-agents-agents-agents
**Date**: May 20, 2026
**Author**: Jack Cheng
**Keywords**: Google I/O, agents, Gemini 3.5 Flash, agentic AI, AI Mode, collaborative agents, delegation agents, Stainless acquisition, MCP, Anthropic

## Elevator pitch
Google I/O 2026 was a full-throated bet on agents as the primary product layer, with Gemini 3.5 Flash powering everything from a redesigned AI-native search to 24/7 personal agents that work while you sleep.

## Takeaways
- Google is bifurcating its agent strategy into "collaborate with" agents (AI Mode search, Antigravity dev platform) and "delegate to" agents (Gemini Spark, Daily Brief, Universal Cart)
- Gemini 3.5 Flash claims 4x faster speed at half the cost of comparable models, and is the engine powering most new agentic features
- Anthropic acquired Stainless for a reported $300M — a developer tools company used by OpenAI and Google — to improve Claude's ability to connect to external tools and data via MCP
- AI Mode is becoming the default search experience, with the ability to build custom mini-apps and interactive visualizations directly within search
- Gemini Spark represents the always-on agent category: cloud-resident, multi-device, operating across Gmail, Docs, Chrome, and third-party tools

## Synthesis
Google I/O 2026 made one thing explicit: the agent layer is now the product. The announcements clustered around a clear strategic split between agents you work alongside and agents you hand off work to entirely. The "collaborate with" category includes an AI Mode that is now the default search experience — the biggest interface change to Google Search in 25 years — with the ability to generate custom mini-apps and interactive visualizations directly from the search box. Antigravity 2.0, Google's agentic development platform, is graduating to a desktop app that lets users orchestrate teams of agents for coding, design, and other creative work.

The "delegate to" bucket is where things get more ambitious. Gemini Spark is pitched as a 24/7 personal agent that lives in the cloud, operates when devices are off, and spans Gmail, Docs, Workspace, Chrome, and eventually third-party tools through MCP. Daily Brief scans your inbox, calendar, and tasks overnight to hand you a morning digest. Universal Cart extends agentic shopping across merchants. At the heart of all this is Gemini 3.5 Flash, which Google claims runs four times faster and at half the cost of comparable frontier models.

The other major signal this week was Anthropic's acquisition of Stainless for a reported $300 million. Stainless builds developer tools for high-quality APIs, and its customers included OpenAI and Google — meaning Anthropic now owns a toolchain used by its top competitors. CEO Alex Rattray previously laid out principles for making MCP servers intuitive for LLMs: keep tool counts small, use precise names, and generate tightly defined outputs. The acquisition signals that the API layer — the "plumbing" that lets agents actually interact with software — is becoming a strategic battleground, not just an afterthought.
