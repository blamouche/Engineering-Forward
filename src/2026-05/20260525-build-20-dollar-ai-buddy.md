# How to Build a $20 Physical AI 'Buddy' with Claude Code
**Source**: https://www.chatprd.ai/how-i-ai/workflows/how-to-build-a-20-physical-ai-buddy-with-claude-code
**Date**: May 25, 2026
**Author**: ChatPRD (from Felix Rieseberg interview)
**Keywords**: Claude Code, hardware, Bluetooth, physical AI, approval button, maker, DIY

## Elevator pitch
A step-by-step guide to building a $20 physical AI companion using Claude Code: acquire a small LCD/Wi-Fi/Bluetooth device, describe the desired behavior in natural language, let Claude write all the low-level code, and connect it to Claude Desktop as a physical approval button.

## Takeaways
- The hardware is a ~$19 self-contained device with LCD screen, Wi-Fi, and Bluetooth — no soldering or embedded systems knowledge required.
- All code is generated by Claude Code from a natural language description: "I want my little Claude to live on this thing..."
- Integration is through the Claude Desktop app's Developer Mode (Help > Troubleshooting > Enable Developer Mode).
- The buddy lights up, makes sounds, and displays prompts when Claude needs permission — physically pressing the button grants approval.
- The feature is now built into the Claude Desktop app for anyone to use, not just developers.

## Synthesis
This workflow guide distills Felix Rieseberg's hardware buddy project into actionable steps. The key insight is that the barrier between software and hardware has been dramatically lowered by AI coding agents. A $19 device with basic capabilities (LCD, Wi-Fi, Bluetooth) can be programmed entirely through natural language — no C, no embedded toolchains, no datasheet diving.

The workflow mirrors the "abstraction ladder" philosophy: instead of learning Bluetooth protocols and writing low-level code, describe the desired behavior in plain English and let Claude handle the implementation. The integration with Claude Desktop's Developer Mode makes the physical interaction seamless — the buddy becomes a tangible extension of Claude's permission system, lighting up and chiming when approvals are needed.

This is noteworthy not for technical complexity but for accessibility. Physical computing has traditionally been gated behind specialized knowledge. AI-assisted hardware programming removes that gate, enabling a new category of "software people building hardware things" without the traditional learning curve. The fact that Anthropic integrated this directly into the Claude Desktop app suggests they see physical interaction as a meaningful product direction, not just a demo.
