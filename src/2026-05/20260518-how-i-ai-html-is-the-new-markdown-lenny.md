# How I AI: HTML is the New Markdown — How Anthropic Engineers Are Building with Claude Code

**Source:** [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-i-ai-html-is-the-new-markdown)
**Date:** 2026-05-18
**Host:** Lenny Rachitsky
**Guest:** Thariq Shihipar (Anthropic, Claude Code team)

## Summary

Interview with Thariq Shihipar recorded live at Anthropic's Code with Claude event. He demonstrates how HTML artifacts replace Markdown for planning, specs, throwaway micro-apps, and living design systems — keeping humans in the loop as agents do more work.

## Biggest Takeaways

1. **HTML > Markdown for AI communication** — HTML offers richer expression (interactive elements, visual mockups, scrollable sections) vs. Markdown's limits. As plans grow to thousands of lines, HTML makes content actually engageable.

2. **Engineers = "Compute allocators"** — when Claude runs 8 hours on a single task ($500 of compute), the critical skill is deciding what's worth building and staying in sync with the agent.

3. **Throwaway UIs for editing** — build custom gamified UIs for editing specific parts of plans, use them, discard them. "Micro software on top of micro software."

4. **Future = readable interfaces, not more text** — Thariq stopped reading thousand-line Markdown plans; HTML made him want to read again by making work legible.

5. **Living HTML design systems** — a single HTML file encoding colors, typography, spacing, components. Portable, human- and machine-readable, no tradeoffs.

6. **Simple prompts win** — "Create an HTML file... whatever is needed to give me maximum context." Over-constraining produces worse results than trusting instructions.

7. **~1% of tokens go to production code** — 99% goes to dashboards, interfaces, status updates, tools for understanding what to build.

8. **Test verification ≠ testing** — managed agents checking outcomes, verification rubrics, Claude recording videos of what it did.

9. **Just-in-time docs > centralized templates** — when content is free and AI can find anything, what matters is quality of ideas.

10. **Be nice to Claude** — no rigorous A/B test, but being kind creates a better world. Stern models produce sad reasoning.
