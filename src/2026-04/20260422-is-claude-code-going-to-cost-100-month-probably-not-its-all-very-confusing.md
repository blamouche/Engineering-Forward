# Is Claude Code going to cost $100/month? Probably not—it’s all very confusing
**Source**: https://simonwillison.net/2026/Apr/22/claude-code-confusion
**Date**: April 22, 2026
**Author**: Simon Willison
**Keywords**: Anthropic, pricing, Claude Code, trust, developer tools

## Elevator pitch
Anthropic briefly exposed a higher Claude Code price point, and the backlash showed how fragile trust is when key developer tools feel unpredictably repriced.

## Takeaways
- Anthropic briefly showed Claude Code as a Max-plan feature, implying a jump from $20 to $100 per month for some users.
- The company quickly reverted the public pricing page while saying a limited test was affecting a small subset of new signups.
- The episode created confusion because public documentation changed before any clear formal communication appeared.
- For users, pricing uncertainty can be as damaging as an actual price increase because it changes adoption risk.
- The incident gives competitors like OpenAI an opening to position stability and transparency as product advantages.

## Synthesis
This post is less about the absolute cost of Claude Code than about the operational importance of pricing trust for developer platforms. Anthropic appears to have briefly exposed a version of its pricing page that moved Claude Code access from the Pro plan to much more expensive Max tiers, then reversed the change after backlash. Even if the test affected only a subset of users, the public presentation triggered a broader reaction because the pricing page, docs, and messaging all pointed in different directions.

That inconsistency matters because coding agents are not casual consumer features. People invest time in workflows, training materials, internal adoption, and team habits around them. Once a tool becomes part of how engineers work, perceived pricing instability changes the platform risk profile. A fivefold jump in the visible entry price, even temporarily, makes users ask whether they are building on something that may become inaccessible to colleagues, clients, or students.

The post also shows how product strategy now includes communications discipline. Running growth experiments on a core developer tool without a coordinated explanation creates brand damage that can outweigh whatever revenue insight the experiment was meant to uncover. In competitive markets, trust and predictability can be as important as technical quality.

The deeper signal is that the coding-agent market is maturing. Pricing is no longer just a monetization lever. It is part of adoption strategy, ecosystem positioning, and educational reach. Vendors that want to become default tools for developers will need not only strong product performance but also clear, credible commitments about access and pricing.
