# Codex for (almost) everything

**Source**: https://openai.com/index/codex-for-almost-everything/
**Date**: April 20, 2026
**Author**: OpenAI
**Keywords**: codex, computer use, plugins, memory, automations

## Elevator pitch
OpenAI is expanding Codex from a coding assistant into a broader desktop work platform with computer use, browser control, image generation, memory, plugins, and long-running automations.

## Takeaways
- Codex can now operate the computer directly with background computer use and multiple parallel agents.
- The app adds an in-app browser, image generation, richer previews, PR review support, and SSH access to remote devboxes.
- OpenAI is shipping more than 90 new plugins and integrations to extend Codex across common developer tools.
- Automations and memory push Codex toward persistent, context-aware, long-running work rather than isolated prompts.
- The release positions Codex as a unified workspace for moving across the full software development lifecycle.

## Synthesis
OpenAI’s latest Codex release pushes the product decisively beyond coding autocomplete and into the territory of a full personal work environment. The announcement bundles several major capability expansions: direct computer use with its own cursor, parallel agents that can operate without blocking the user, an in-app browser for web-facing workflows, native image generation, richer file previews, and new ways to interact with GitHub review comments, terminals, and remote development boxes. Just as important, OpenAI is broadening Codex’s integration surface through more than 90 new plugins that connect the product to developer, productivity, and enterprise tools. The cumulative effect is to make Codex less of a narrow coding tool and more of an orchestration layer for the entire software development lifecycle. Memory and automations deepen that shift. Codex can now retain useful context, remember preferences and corrections, reuse long-running threads, and schedule future work, which means it starts to behave like an ongoing collaborator rather than a single-session assistant. OpenAI also emphasizes proactive suggestions, using project state and connected tools to recommend next actions. That is a meaningful product direction because it reframes AI from a request-response interface into a system that can keep work moving between human interventions. The announcement effectively stakes out the claim that the winning developer assistant will not just write code, but coordinate files, browsers, reviews, tasks, and context across the rest of the workflow.
