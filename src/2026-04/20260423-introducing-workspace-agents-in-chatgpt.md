# Introducing workspace agents in ChatGPT

**Source**: https://openai.com/index/introducing-workspace-agents-in-chatgpt
**Date**: April 23, 2026
**Author**: OpenAI
**Keywords**: OpenAI, workspace agents, ChatGPT, Codex, enterprise AI, Slack, workflows

## Elevator pitch
OpenAI is turning GPTs into shared, cloud-run workplace agents that can use tools, run code, remember context, and operate inside Slack and ChatGPT with enterprise controls.

## Takeaways
- Workspace agents are positioned as the organizational successor to custom GPTs.
- They run on Codex infrastructure, giving them files, tools, memory, code execution, and scheduling.
- OpenAI wants agents to live in work surfaces such as Slack, not only inside ChatGPT.
- The product emphasizes approvals, admin controls, analytics, and auditability because agents can take real actions.
- Pricing will switch from free preview to credit-based usage after May 6, 2026.

## Synthesis
Workspace agents are one of OpenAI’s clearest moves away from the idea that enterprise AI is mainly about better chat interfaces. The product turns the GPT concept into something closer to a managed runtime for recurring work. These agents can be shared across a team, run in the cloud when no one is actively watching, connect to business tools, use code and memory, and show up inside Slack as well as ChatGPT. That combination matters because the most valuable enterprise workflows are rarely single-turn conversations. They involve coordination, context gathering, handoffs, and decisions across systems.

The Codex substrate is a big part of why this launch matters. Once an agent can execute code, manipulate files, maintain persistent context, and operate on a schedule, it becomes materially more useful than a customized chatbot. It can prepare reports, qualify leads, route feedback, and carry through multi-step processes. OpenAI is effectively packaging parts of its coding-agent infrastructure as a general-purpose workplace automation layer.

The post is also careful about governance, and that is probably wise. Agents that can write to spreadsheets, send emails, update CRMs, or file tickets create new operational risk. Approval gates, role-based access, compliance logging, and admin visibility are not side features here. They are part of the product’s core value proposition. Enterprises will only adopt these systems broadly if they feel the automation is inspectable and controllable.

Seen more broadly, workspace agents represent OpenAI’s attempt to move up the stack from model provider to workflow platform. If custom GPTs were reusable prompts, workspace agents are reusable coworkers. The long-term bet is that organizations will not just chat with AI. They will build fleets of internal agents that absorb shared process knowledge and keep work moving across the software surfaces where teams already spend their time.
