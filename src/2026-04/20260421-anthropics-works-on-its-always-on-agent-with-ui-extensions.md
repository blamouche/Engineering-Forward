# Anthropics works on its always-on agent with UI extensions
**Source**: https://www.testingcatalog.com/anthropics-works-on-its-always-on-agent-with-new-ui-extensions/
**Date**: April 21, 2026
**Author**: Unknown
**Keywords**: Anthropic, Claude, agents, extensions, UI

## Elevator pitch
Anthropic appears to be building a persistent Claude-based agent runtime where extensions can ship their own UI tabs, pushing agents toward reusable mini-app ecosystems rather than pure chat features.

## Takeaways
- TestingCatalog says Anthropic is developing an always-on agent codenamed Conway.
- The system reportedly includes container lifecycle controls, model selection, connectors, webhooks, and fine-grained permissions.
- Recent mobile builds suggest Anthropic wants parity between desktop and phone management surfaces.
- New “Installed” and “Built-in” sections hint at an extension ecosystem with packaged UI tabs.
- The concept turns a persistent agent into a modular runtime for dashboards and workflow-specific mini-apps.

## Synthesis
The reported Conway work at Anthropic is interesting because it pushes the agent category beyond the idea of a background worker and toward something more like an extensible runtime. According to TestingCatalog, Conway is an always-on Claude environment that will eventually surface directly in Anthropic’s main UI, complete with connectors, webhooks, extension management, model selection, tool-call tuning, and container lifecycle controls.

Those capabilities already point to a more serious platform play than a typical assistant feature. But the most intriguing reported detail is the emergence of upgraded extensions that can ship custom UI tabs. If accurate, that would give Anthropic a path toward agent-powered mini-apps that live alongside the main Claude conversation rather than only behind it.

That matters because many valuable workflows are awkward to express purely in chat. Mission control dashboards, structured review interfaces, lightweight admin panels, operational monitors, and vertical workflow tools all benefit from dedicated UI. By letting extensions carry their own interfaces, Anthropic could turn persistent agents into application hosts rather than just conversational endpoints.

The report also emphasizes mobile parity. iOS builds apparently include a full settings interface for installing extensions, managing connectors and webhooks, switching models, and controlling container lifecycle. That is a meaningful clue about product ambition. Desktop-only experiments are easy to dismiss as niche power-user features. Mobile parity suggests Anthropic wants the always-on agent to feel like a first-class product surface.

There is also an ecosystem angle here. The reported “Installed” and “Built-in” sections sound like the early scaffolding of a marketplace or package model, where reusable extensions expose both behavior and interface. That would align with a broader industry trend toward packaging agent capabilities as portable modules rather than handcrafted prompt setups.

If this launches close to the reported shape, the strategic significance is large. Claude would no longer just be an assistant that happens to use tools. It would become a persistent environment where tools, interfaces, permissions, and workflows can be bundled together and reused. That starts to resemble an operating system for agentic work more than a chat app.

As always with pre-release reporting, timing and final scope are uncertain. But the direction is plausible and important. The future of agents probably involves much more than invisible background automation. It likely includes persistent runtimes, explicit permissions, and UI surfaces that make agent behavior legible and controllable. Conway appears to be Anthropic’s attempt to build exactly that.
