# Awesome LLM Apps: Curated Collection of Production LLM Applications
**Source**: https://github.com/Shubhamsaboo/awesome-llm-apps
**Date**: April 3, 2026
**Author**: Shubham Saboo
**Keywords**: LLM apps, RAG, AI agents, multi-agent, MCP, voice agents, open source

## Elevator pitch
A comprehensive curated collection of practical LLM application implementations spanning RAG, AI agents, multi-agent teams, MCP, and voice agents across diverse domains with multi-model support.

## Takeaways
- Multi-model support covering OpenAI, Anthropic, Google Gemini, xAI, and open-source models like Llama and Qwen
- Diverse agent types from starter-level for learning to advanced autonomous game-playing and voice-enabled agents
- Technology implementations include RAG systems, agent teams, memory-enhanced LLMs, fine-tuning tutorials, and integration patterns
- Practical applications spanning finance, healthcare, recruiting, creative industries, and research
- Educational resources include framework crash courses for Google ADK and OpenAI SDK plus cost optimization techniques

## Synthesis
The Awesome LLM Apps repository serves as a comprehensive resource hub for developers building practical applications with large language models. Rather than focusing on theoretical implementations or benchmarks, the collection emphasizes runnable, well-documented examples that demonstrate how LLM capabilities can be applied to real-world problems across diverse domains.

The multi-model philosophy reflects current best practices in production LLM development. By providing implementations across OpenAI, Anthropic, Google Gemini, xAI, and open-source alternatives, the collection enables developers to understand the trade-offs between different providers and select appropriate models for their specific use cases and budget constraints.

The agent taxonomy is particularly valuable for understanding the current state of the field. Starter-level agents provide approachable entry points for developers new to agentic systems. Advanced single and multi-agent implementations demonstrate production-ready patterns for autonomous workflows. Specialized categories like autonomous game-playing agents and voice-enabled agents showcase emerging capabilities that are increasingly finding production applications.

The inclusion of Model Context Protocol agents reflects the growing importance of standardized tool integration. MCP has emerged as a key infrastructure layer for connecting AI agents to external services and data sources, and having reference implementations helps developers understand proper integration patterns.

The technology stack coverage is broad: RAG systems for knowledge retrieval, agent teams for collaborative workflows, memory-enhanced applications for persistent context, and fine-tuning tutorials for domain adaptation. This breadth allows the repository to serve as a reference for diverse development scenarios rather than a narrow specialty resource.

Educational resources including framework crash courses for Google ADK and OpenAI SDK acknowledge that developers need not just code examples but conceptual understanding of the frameworks powering modern agent systems. The token optimization techniques address practical economics: inference costs at scale require deliberate attention to efficiency.
