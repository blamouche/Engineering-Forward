## Elevator pitch
Two How I AI episodes explore design-code bidirectional sync at Figma and how LinkedIn's Editor in Chief ships production iOS apps without traditional coding using a dual-agent workflow.

## Takeaways
- Figma's approach enables pulling live production interfaces into Figma, making edits, and pushing changes back to code—eliminating traditional handoff bottlenecks
- "Direct manipulation still beats prompting for precision" for fine-tuning designs—suggesting AI augments but doesn't replace visual design tools
- Daniel Roth (LinkedIn Editor in Chief) ships production apps with a dual-agent system where one AI generates code and another reviews for quality and security
- AI scanning of daily communications to identify overlooked tasks is a practical management workflow
- Both episodes emphasize structured workflows, AI-readable code organization, and comprehensive documentation

## Synthesis
The two episodes curated in this newsletter issue share a common thread: AI enabling non-traditional development workflows that wouldn't have been possible two years ago, combined with honest acknowledgment of where human judgment and specialized tools still dominate.

The Figma design-code bidirectional sync episode with Gui Seiz and Alex Kern addresses one of the most persistent pain points in product development: the gap between design tools and code implementation. Traditional workflows treat design and code as sequential steps with a "handoff" moment where designers deliver specifications that engineers then implement. Bidirectional sync collapses this into a continuous loop—designers can pull the actual production interface into Figma, make changes, and have those changes reflected back in code. The elimination of handoff reduces the time between design decision and live implementation from days to hours or minutes.

The observation that "direct manipulation still beats prompting for precision" is a useful calibration signal. Despite remarkable AI code generation capabilities, the experience of clicking and dragging in a visual design tool remains faster and more accurate for precise positional and dimensional adjustments than describing the desired outcome in natural language. AI tools amplify capability on the high-leverage tasks (structural changes, new component generation) while traditional tools remain superior for fine-tuning.

Daniel Roth's production iOS app development story is the more remarkable case. As LinkedIn's Editor in Chief, Roth is not a software engineer by training or role. His dual-agent workflow—one AI generating code, another reviewing for quality and security—creates an automated code review loop that catches issues a non-technical developer might miss. This pairing reflects mature understanding of AI-assisted development: generation and review are separate cognitive tasks that benefit from separation, even when both are performed by AI systems.
