# Claude Code and Cowork can now use your computer
**Source**: https://www.engadget.com/ai/claude-code-and-cowork-can-now-use-your-computer-210000126.html
**Date**: Unknown
**Author**: Unknown
**Keywords**: Claude Code, Claude Cowork, computer use, automation, Anthropic

## Elevator pitch
Anthropic is expanding Claude Code and Claude Cowork with “computer use” capabilities so the assistant can open files, browse the web, and run tools on macOS, while still requiring user approval for actions.

## Takeaways
- Claude Code and Cowork can now operate on a user’s computer to complete tasks.
- The system prioritizes connector-based access (e.g., Google Workspace, Slack) but can act without a connector.
- Anthropic positions the feature as a research preview with ongoing adjustments.
- Users must grant permission for actions, and sensitive data handling is discouraged.
- Computer use is initially limited to Claude Pro and Claude Max on macOS.

## Synthesis
Engadget reports that Anthropic has upgraded both Claude Code and Claude Cowork with “computer use” functionality, enabling the assistant to open files, browse the web, and run developer tools on a user’s machine. The new capability is designed to let Claude complete more end‑to‑end tasks instead of only providing suggestions, bringing it closer to an agent that can execute workflows directly.

The update emphasizes a layered access model. Claude is expected to prioritize first‑party connectors to services like Google Workspace and Slack when available. When a connector doesn’t exist, the assistant can still proceed by interacting directly with the computer’s interface. This expands the range of tasks it can handle, but Anthropic also notes that the system should ask permission before taking actions, and it advises users to avoid using the feature for sensitive information as a precaution.

The functionality is labeled a research preview, signaling that reliability, safety, and user experience are still evolving. Anthropic is positioning this as a feedback‑driven rollout rather than a fully stable product feature. The company also notes the integration with Dispatch, which allows continuous conversations across phone and desktop, implying a cross‑device workflow where Claude can receive instructions in one place and execute them on another.

From a product perspective, the update bridges two related offerings: Claude Code, aimed at programmers, and Claude Cowork, framed as a more general assistant for non‑technical users. By enabling “computer use,” Anthropic makes both tools more action‑oriented, turning them into systems that can manipulate files, navigate applications, and execute routines instead of simply advising.

The initial release is limited to macOS and to Claude Pro and Claude Max subscribers. The restrictions suggest Anthropic is controlling the rollout to gather feedback and manage risk while validating the feature’s stability. Overall, the announcement signals a shift from conversational AI toward agentic operation in desktop environments, with explicit guardrails around permissions and sensitive data.
