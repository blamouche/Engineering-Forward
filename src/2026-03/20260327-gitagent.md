# gitagent | your repository becomes your agent
**Source**: https://github.com/open-gitagent/gitagent
**Date**: Unknown
**Author**: open-gitagent
**Keywords**: agents, standards, git, compliance, workflows

## Elevator pitch
gitagent proposes a git‑native, framework‑agnostic standard for defining AI agents so any repo can become a portable, versioned agent configuration.

## Takeaways
- Defines a minimal agent spec centered on `agent.yaml` and `SOUL.md`.
- Separates identity, rules, skills, tools, memory, and workflows into a repo layout.
- Supports adapters to export agents to Claude Code, OpenAI, CrewAI, Gemini, OpenClaw, etc.
- Emphasizes compliance features like segregation of duties and audit trails.
- Provides a CLI for validation, export, import, and compliance audits.

## Synthesis
gitagent frames AI agents as git repositories rather than framework‑specific configs. The core idea is that version control already provides collaboration, auditability, and rollback—so an agent’s identity and behavior should live in a repo structure that any runtime can consume. The standard requires only two files: `agent.yaml` (manifest) and `SOUL.md` (identity/persona). Everything else—rules, skills, tools, memory, workflows, hooks, compliance artifacts—is optional but structured for scale.

The proposed repo layout resembles a software project: skills, tools, and workflows are modular; memory and knowledge folders persist context; and hooks define lifecycle automation. This structure enables patterns like agent versioning with git history, branch‑based deployments, human‑in‑the‑loop PR approvals, and shared skills in monorepos.

A major differentiator is compliance. gitagent includes first‑class support for financial regulations (FINRA, Federal Reserve, SEC/CFPB) and segregation of duties. The spec allows defining roles, conflicts, handoffs, and enforcement levels, with validation and audit tooling baked into the CLI.

Interoperability is handled via adapters. The CLI can export or run agent definitions across ecosystems (Claude Code, OpenAI Agents SDK, CrewAI, Gemini CLI, OpenClaw, etc.), positioning gitagent as the identity layer while leaving orchestration to each framework.

Overall, gitagent is an attempt to standardize the “agent identity” problem: a portable, auditable, and composable spec that treats agent behavior like code—versioned, reviewed, and deployable across runtimes.
