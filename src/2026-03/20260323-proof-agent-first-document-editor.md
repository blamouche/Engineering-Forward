# Proof — The Agent-First Document Editor
**Source**: https://proofeditor.ai
**Date**: March 23, 2026
**Author**: Unknown
**Keywords**: collaborative editor, agents, provenance, comments, real-time docs

## Elevator pitch
Proof positions itself as a collaborative document editor built for humans and agents, emphasizing shared documents, live presence, and provenance.

## Takeaways
- Proof is pitched as a document editor designed for human‑agent collaboration.
- Core features include live presence, comments, and suggestions in shared docs.
- Provenance is a central value: users can see who wrote what.
- The product aims to make agent interactions in documents feel first‑class.
- The messaging focuses on workflow integration rather than standalone AI chat.

## Synthesis
The Proof homepage introduces the product as an “agent‑first document editor,” framing collaboration as a shared space where humans and AI agents work side by side. Unlike tools that bolt AI onto existing editors, Proof positions the agent as a full participant in the document workflow. The promise is a single shared doc with live presence, comments, and suggestions, but with clear provenance so readers can see which parts were written by which contributor.

The central value proposition is accountability. In many AI‑augmented writing workflows, it can be difficult to track where content came from or to audit edits produced by a model. Proof foregrounds provenance as a way to make agent contributions visible, making it easier for teams to trust and review AI outputs. This is a subtle but important distinction: rather than optimizing for raw writing speed, the tool optimizes for transparency and reviewability.

Another theme is collaboration at the document level rather than the chat level. Proof suggests that the document itself is the workspace, with agents acting inside it rather than in a separate prompt window. The emphasis on live presence and comments implies a multi‑actor environment where humans can guide, critique, and edit alongside automated collaborators. This aligns with broader trends in agentic tooling that treat AI as a teammate integrated into the workflow rather than a separate assistant.

While the homepage is sparse on technical details, it implies that Proof is designed to handle simultaneous edits, maintain a shared state, and keep a clear attribution layer. These are essential capabilities for any editor that aims to support both humans and AI agents without confusion. In practice, this means ensuring that agent suggestions are distinguishable from human edits and that teams can audit changes before accepting them.

Overall, Proof is positioned as a purpose‑built environment for human‑agent collaboration in writing. Its differentiator is not just AI assistance, but the scaffolding—presence, comments, and provenance—that makes that assistance trustworthy in multi‑person workflows. The pitch is less about magic text generation and more about a structured, reviewable collaboration layer that can scale as teams rely more on agents for drafting and editing.
