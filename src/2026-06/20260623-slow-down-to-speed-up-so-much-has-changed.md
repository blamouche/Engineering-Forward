# Slow Down to Speed Up: So Much Has Changed in 6 Months' Time
**Source**: https://newsletter.pragmaticengineer.com/p/slow-down-to-speed-up
**Date**: 2026-06-23
**Author**: Gergely Orosz
**Keywords**: AI agents, engineering transformation, Meta outage, code review, agentic engineering, software quality, Anthropic, OpenAI, Uber

## Elevator pitch
Gergely Orosz's Craft Conference keynote documents how the past six months have transformed software engineering—from the models released in November 2025 that elevated agents to genuine usefulness, through Meta's AI-psychosis outage, to the industry-wide shift toward agent-driven development and its quality implications.

## Takeaways
- Meta's worst-ever outage was caused by AI-generated, AI-reviewed code with zero human input, compounded by security teams gutted by layoffs and forced reassignments to AI training—illustrating the danger of prioritizing AI speed over engineering fundamentals
- The models released in November 2025 (Opus 4.5, GPT-5.4) elevated agents to genuine usefulness; since then, individual developer productivity is up 2.5x (Cursor data), but team productivity appears flat
- Pull request sizes are up 3x versus 18 months ago, and more changes are being accepted without human review—starting around February 2026 when Opus 4.7 and GPT-5.5 launched
- At Anthropic, Boris Cherny runs ~5 parallel agents shipping 20-30 PRs/day; ~70-90% of code inside Anthropic is generated by Claude; PRDs are dead and replaced by prototypes; Claude Cowork was built in 10 days
- At OpenAI's Codex team, there's a "fix this" button in their mobile app for one-shot bug fixes; most devs run several agents in parallel with laptop lids open to prevent sleep; "taste" is becoming a core skill

## Synthesis
The article is a comprehensive overview of how software engineering has fundamentally changed since November 2025. Orosz opens with Meta's catastrophic outage—where AI-generated, AI-reviewed code enabled account takeovers via a "zero auth" policy—as a warning about what happens when AI focus eclipses basic engineering health. Instagram lost 44% of its design team, the Developer Documentation team suffered a 95% headcount reduction, and Trust & Safety lost ~50% of staff to data labeling and layoffs.

The data from Cursor and Linear tells a striking story: developers using AI harnesses produce 2.5x more code than 18 months ago, PR sizes are 3x larger, and more changes ship without human review. At Anthropic, code generation rates are even higher: 70-90% of code is AI-generated, and the product team uses Claude for code, analytics, support, and debugging through Claude Tag (the new Slack-based workflow).

Orosz catalogues how different companies are adapting. Uber built an entire internal AI infrastructure stack including MCP Gateway, Agent Builder, AIFX CLI, Minion background agents, Code Inbox with smart assignments and risk profiles, uReview for AI code review, and Autocover/Shepherd for large-scale migrations. Traditional companies like Cisco (18,000 developers using Codex for migrations) and JP Morgan Chase (multi-agent annotation framework) are not lagging behind startups.

Industry trends include token budgets becoming like trading portfolios (the Every/Token Tightening theme), vanishing middle management as AI handles coordination, CEOs and CTOs returning to coding, falling software quality, GitHub's reliability woes, and AI slop overwhelming quality-focused developers. Orosz's advice: slow down to speed up—invest in code review, validation, and the fundamentals that AI can accelerate but shouldn't replace.
