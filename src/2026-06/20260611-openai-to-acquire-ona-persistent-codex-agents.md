# OpenAI to Acquire Ona: Persistent Cloud Environments for Long-Running Codex Agents
**Source**: https://openai.com/index/openai-to-acquire-ona/
**Date**: June 11, 2026
**Author**: OpenAI
**Keywords**: OpenAI, Ona acquisition, Codex, long-running agents, cloud execution, persistent environments, enterprise deployment, agent orchestration

## Elevator pitch
OpenAI is acquiring Ona to give Codex agents secure, persistent, customer-controlled cloud environments where they can continue working across hours or days — even when laptops are closed — as more than 5 million weekly Codex users move from experimentation to production deployment.

## Takeaways
- More than 5 million people use Codex each week, up 400% from earlier this year, and the tool has expanded beyond software developers to a wider range of knowledge workers.
- Codex's most valuable work now unfolds over hours or days rather than minutes, creating a need for agents to continue working beyond a single device or active session.
- Ona provides secure, persistent cloud environments where agents can access tools, systems, and context over time, with control over where they run, what they can access, and how credentials are scoped.
- The customer-controlled execution model allows agents to operate inside an organization's own cloud environment while OpenAI provides the intelligence and orchestration.
- Ona has helped 2 million developers work in secure, reproducible cloud environments, bringing directly relevant experience to Codex's next phase.

## Synthesis
OpenAI announced that it will acquire Ona, bringing its secure cloud execution and orchestration technology into the Codex ecosystem. The acquisition addresses a structural limitation of current AI coding agents: their work is tied to a single device or active session. As Codex has grown to more than 5 million weekly users — up 400% from earlier this year — and expanded beyond software developers to a wider range of knowledge workers, its most valuable work has shifted from minutes to hours or days. OpenAI's position is that users should be able to delegate more ambitious work without remaining tethered to the machine where it began.

Ona's technology provides secure, persistent environments where agents can access the tools, systems, and context they need to make progress over time. The company has spent years helping developers move software development from local machines into the cloud, serving 2 million developers with secure, reproducible cloud environments. That experience is directly relevant to the next phase of Codex, where agents need to continue working inside a customer's cloud environment even when laptops are closed. The acquisition signals that the bottleneck for enterprise agent deployment is shifting from model capability to infrastructure: organizations need control over where agents run, what they can access, how credentials are scoped, how activity is logged, and how work moves through review.

Ona's customer-controlled execution model allows agents to operate inside an organization's own cloud environment while OpenAI provides the intelligence and orchestration. This gives organizations greater control over their infrastructure, data, and security boundaries without limiting what Codex can accomplish. After closing, the Ona team will join OpenAI and work with the Codex team to advance secure, persistent enterprise execution capabilities and help scale Codex to more enterprises worldwide. The acquisition reflects a broader industry trend: as agents take on longer, more complex tasks, the infrastructure that hosts them becomes as important as the models that power them, and the companies that provide both the intelligence and the trusted workspace will have a structural advantage in the enterprise market.
