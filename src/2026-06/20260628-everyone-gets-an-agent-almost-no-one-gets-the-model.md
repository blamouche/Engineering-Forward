# Everyone Gets an Agent. Almost No One Gets the Model.
**Source**: https://every.to/context-window/everyone-gets-an-agent-almost-no-one-gets-the-model
**Date**: 2026-06-28
**Author**: Kate Lee (Every)
**Keywords**: GPT-5.6, AI access, agent infrastructure, Codex, Claude Tag, compound engineering, token rationing

## Elevator pitch
OpenAI released GPT-5.6 Sol under restricted access to ~20 pre-approved companies, signaling a new era where frontier models are rationed while agents built on older models proliferate—everyone gets an agent, almost no one gets the model.

## Takeaways
- GPT-5.6 Sol was released on June 27, 2026, but access is limited to roughly 20 pre-approved companies under U.S. government directive
- Dan Shipper argues this lockout hurts independent builders, students, and professionals who need frontier tools to compete
- Token access is becoming allocated like capital: the biggest budgets will go to whoever proves the biggest returns
- Codex has crossed 5 million weekly active users; Anthropic's Claude Tag landed in Slack as a shared team agent
- Every's compound engineering plugin now runs coding agents unattended for hours, building features, writing tests, and opening PRs autonomously
- Mike Taylor predicts tokens will be allocated with risk limits and auditing, similar to financial trading portfolios
- Nityesh Agarwal argues Claude Code is the OpenClaw alternative people already have—marketed as a coding tool but actually a general-purpose agent harness

## Synthesis
The release of GPT-5.6 Sol under restricted access marks a watershed moment in AI distribution. While OpenAI made the model available on June 27, 2026, the U.S. government directed that access be limited to approximately 20 pre-approved companies while Washington works out how to release frontier models with advanced capabilities. This creates a stark divide: agents built on existing models (Codex, Claude Tag) are becoming ubiquitous, but the most powerful models themselves are increasingly gated.

Dan Shipper's argument is that this rationing disproportionately harms the people who most need these tools—independent builders, ambitious students, and working professionals who lack the institutional backing of large companies. Meanwhile, Mike Taylor's analysis suggests this is just the beginning of a broader trend: token access will be allocated like trading portfolios, with the largest compute budgets going to those who can prove the highest returns. Companies like Uber, Meta, Amazon, and Walmart have already moved to cap employee AI use.

On the agent infrastructure side, the landscape is rapidly evolving. Codex has crossed 5 million weekly active users, and Anthropic's Claude Tag represents a new category of shared Slack-based agents for collaborative work. Every's own compound engineering approach demonstrates that agents can now run unattended for hours—building features, writing tests, and opening pull requests without human intervention. The practical implication is that while frontier model access narrows, the agent ecosystem built on available models continues to broaden and deepen.
