Anthropic Works on Knowledge Bases for Claude Cowork

January 18, 2026 Alexey Shabanov Claude, Anthropic, knowledge bases, Cowork, productivity agent, MCP, Model Context Protocol
Read the source article

Quick summary

Anthropic is developing persistent knowledge bases for Claude that the assistant can proactively reference and incrementally update, signaling a shift from chat assistant to comprehensive productivity agent.

Key takeaways

  • Claude is gaining persistent knowledge repositories that it can proactively check for relevant context when answering questions
  • Knowledge bases will be incrementally updated with preferences, decisions, and lessons learned during conversations
  • Cowork is becoming Claude's primary mode, with traditional chat functionality folded into it as an optional mode
  • The MCP (Model Context Protocol) registry is expanding for dynamic connector management
  • Voice mode is being expanded to the web interface, alongside other multimodal improvements
