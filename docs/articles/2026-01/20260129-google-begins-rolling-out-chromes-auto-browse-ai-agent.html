Google Begins Rolling Out Chrome's Auto Browse AI Agent

January 28, 2026 Google, Chrome, Gemini, AI agent, auto browse, agentic AI, browser automation, security
Read the source article

Quick summary

Google integrates Gemini 3-powered agentic AI features into Chrome, including Auto Browse that can autonomously perform multi-step web tasks like vacation planning, form filling, and online shopping across multiple tabs.

Key takeaways

  • Auto Browse is a multimodal AI agent built on Gemini 3 that can research, compare, and execute tasks across multiple websites autonomously
  • Use cases include vacation planning across date options, scheduling appointments, filling forms, collecting tax documents, managing subscriptions, and identifying items from photos to add to shopping carts
  • The feature can access saved passwords and log into services when given permission, enabling end-to-end task automation
  • Security experts warn of prompt-injection vulnerabilities on malicious websites, with Google placing responsibility on users
  • Auto Browse is rolling out in preview in the U.S. for Google AI Pro and Ultra subscribers only
