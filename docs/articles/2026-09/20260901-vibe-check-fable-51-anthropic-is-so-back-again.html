Vibe Check: Fable 5.1 — Anthropic Is So Back (Again)

2026-09-01 Every (Katie Parrott and Dan Shipper) Anthropic, Fable 5.1, Claude, coding agents, model review, Opus 5, ChatGPT, Codex, Cursor, AI writing, Every
Read the source article

Quick summary

Every's team tested Fable 5.1 extensively and found it brings Fable 5's coding ability into a model that's actually pleasant to work alongside — faster, clearer, less argumentative — but it still overruns briefs, invents quotations, and sometimes keeps working when told to stop.

Key takeaways

  • Fable 5.1 is the successor to Fable 5, which Every called the best coder in the world
  • The original Fable was "easier to admire than to use" — enormous coding capacity but slow replies and hard-to-follow explanations
  • Fable 5.1 brings coding ability into a model the team wants to work alongside: faster, writes more clearly, argues less when asked to change course
  • After a summer that sent much of Every's team toward ChatGPT and Codex, they're bringing work back to Claude
  • Fable 5.1 still overruns briefs, can invent quotations, and sometimes keeps working when asked to stop — easier to use doesn't mean ready to leave unchecked
  • Cora GM Kieran Klaassen's rebuild of Proof revealed what replacing the original Fable looks like in practice
  • Katie Parrott now drafts with Fable 5.1 but the automated editing pipeline stays on Opus 5
  • Spiral GM Marcus Moretti's agent tests measured speed and token use differences
