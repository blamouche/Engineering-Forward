Codex for Everything and Everyone

2026-06-25 Laura Entis, Katie Parrott (Every) OpenAI Codex, knowledge work, Sites, plugins, Claude Tag, AI agents, Slack agents
Read the source article

Quick summary

OpenAI is pushing Codex well beyond coding with Sites and role-specific plugins, betting that knowledge workers—not just developers—will adopt it as their primary agentic work surface.

Key takeaways

  • Codex has 5 million weekly active users (vs. ChatGPT's 900 million), but knowledge workers account for ~20% and are growing 3x faster than developer usage
  • OpenAI launched role-specific plugins for financial analysts and product managers, and Sites for presenting outputs to non-technical audiences
  • Every's "Codex for Knowledge Work" guide was updated within a month of its first edition, reflecting rapid feature evolution
  • Anthropic launched Claude Tag, a Slack agent that can be added to channels, connected to tools, and delegated asynchronous work—Anthropic says it created 65% of the product team's code internally
  • Every's Claudie (built on Claude Code since January) validates the shared-agent model: institutional knowledge trumps individual personal assistants in a work context
  • Dan Shipper identifies a bifurcation: work is splitting into "async delegated work with Slack agents" and "collaborative work with Codex or Cowork"
  • AI design "tells" are emerging: Claude Design produces cream-colored backgrounds, large serif typefaces, and "tasteful, slightly askew primary colors" that designers find increasingly recognizable
