Everyone Gets an Agent. Almost No One Gets the Model.

2026-06-28 Kate Lee (Every) GPT-5.6, AI access, agent infrastructure, Codex, Claude Tag, compound engineering, token rationing
Read the source article

Quick summary

OpenAI released GPT-5.6 Sol under restricted access to ~20 pre-approved companies, signaling a new era where frontier models are rationed while agents built on older models proliferate—everyone gets an agent, almost no one gets the model.

Key takeaways

  • GPT-5.6 Sol was released on June 27, 2026, but access is limited to roughly 20 pre-approved companies under U.S. government directive
  • Dan Shipper argues this lockout hurts independent builders, students, and professionals who need frontier tools to compete
  • Token access is becoming allocated like capital: the biggest budgets will go to whoever proves the biggest returns
  • Codex has crossed 5 million weekly active users; Anthropic's Claude Tag landed in Slack as a shared team agent
  • Every's compound engineering plugin now runs coding agents unattended for hours, building features, writing tests, and opening PRs autonomously
  • Mike Taylor predicts tokens will be allocated with risk limits and auditing, similar to financial trading portfolios
  • Nityesh Agarwal argues Claude Code is the OpenClaw alternative people already have—marketed as a coding tool but actually a general-purpose agent harness
