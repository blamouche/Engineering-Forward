Microsoft tests Researcher and Analyst agents in Copilot

2026-02-16 Alexey Shabanov copilot, agents, microsoft
Read the source article

Quick summary

Microsoft is testing a unified Copilot “Tasks” feature that bundles Researcher and Analyst agents with scheduled prompts and a new Auto mode for end-to-end work.

Key takeaways

  • Tasks unifies agentic features in Copilot with freeform and scheduled runs.
  • Researcher and Analyst modes map to existing Microsoft 365 Copilot agents.
  • A new Auto mode appears to combine deep research with browser control.
  • Suggested prompts cover presentations, email summaries, bookings, and reports.
  • The feature looks close but not fully finished, with no public launch date.
