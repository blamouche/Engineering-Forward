Code is Cheap. Show Me the Talk.

2026 Nadh LLM, Software Development, Vibe Coding, FOSS, AI-Assisted Coding, Code Quality
Read the source article

Quick summary

Linus Torvalds' famous "Talk is cheap. Show me the code." has been inverted by LLMs—now articulation and engineering thinking matter more than typing code line by line.

Key takeaways

  • Software development as practiced for decades is fundamentally over; LLM tools have compressed weeks of work into hours for experienced developers
  • Traditional signals of code quality (documentation, comments, organization) are now meaningless since LLMs can generate them effortlessly
  • The value of code now lies in accountability and human provenance, not just functionality
  • FOSS dynamics are shifting as anyone can vibe-code custom solutions, threatening traditional collaboration incentives
  • The real concern is a generation of developers who never develop fundamental skills because they rely entirely on AI assistants
