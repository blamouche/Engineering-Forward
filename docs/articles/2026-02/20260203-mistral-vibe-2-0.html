Mistral Vibe 2.0

February 2026 Mistral AI Coding Agent, CLI, Devstral 2, Vibe Coding, Subagents, Developer Tools
Read the source article

Quick summary

Mistral releases Vibe 2.0, a major upgrade to their terminal-native coding agent powered by Devstral 2, featuring custom subagents, multi-choice clarifications, and slash-command skills.

Key takeaways

  • Vibe 2.0 introduces custom subagents for specialized tasks (deploy scripts, PR reviews, test generation), invokable on demand
  • Multi-choice clarifications prevent blind guessing: Vibe now prompts with options when intent is ambiguous before acting
  • Slash-command skills load preconfigured workflows (deploying, linting, docs) and unified agent modes combine tools, permissions, and behaviors
  • Available on Le Chat Pro ($14.99/month, 50% student discount) and Team ($24.99/seat/month) plans with PAYG for extra usage or BYOK
  • Devstral 2 API pricing: $0.40/$2.00 per million tokens (full model) or $0.10/$0.30 (Small); free tier available on Experiment plan
