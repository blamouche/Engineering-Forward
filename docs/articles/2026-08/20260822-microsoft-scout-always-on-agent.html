Microsoft Scout: Always-On AI Agent for the Microsoft 365 Stack

2026-06-08 TLDR AI microsoft, scout, ai-agent, m365, persistent-agent, automation
Read the source article

Quick summary

Microsoft Scout is an always-on agent for Frontier program users that enhances automation across the Microsoft 365 stack, offering multi-step routines, local file integration, and support for both OpenAI and Anthropic models.

Key takeaways

  • Scout is an always-on agent available to Microsoft Frontier program users, designed for persistent automation in the Microsoft 365 ecosystem
  • Supports multi-step routines that chain operations across M365 applications, integrating with local files and system context
  • Allows users to choose between OpenAI and Anthropic models, rather than being locked to a single provider
  • Currently gated to Frontier program users, positioning Microsoft strategically in the persistent agents space against competitors
  • Represents Microsoft's move from Copilot-as-assistant to Copilot-as-autonomous-agent, a significant shift in product philosophy
