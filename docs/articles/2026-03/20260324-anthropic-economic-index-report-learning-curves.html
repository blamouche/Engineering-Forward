Anthropic Economic Index report: Learning curves

March 24, 2026 Maxim Massenkoff, Eva Lyubich, Peter McCrory, Ruth Appel, Ryan Heller AI adoption, labor economics, usage patterns, Claude, learning curves
Read the source article

Quick summary

Anthropic’s March 2026 Economic Index finds Claude usage is diversifying, shifting toward lower‑wage tasks, and that higher‑tenure users achieve higher success rates—evidence of learning‑by‑doing in AI adoption.

Key takeaways

  • Claude.ai use cases are less concentrated; top‑10 tasks fell from 24% to 19% of traffic.
  • Task value on Claude.ai dipped slightly as usage expanded to more personal and lower‑wage tasks.
  • API usage concentrates more in coding and automation, while Claude.ai shifts to broader use.
  • Higher‑tenure users have ~10% higher success rates and tackle higher‑value tasks.
  • Adoption inequality persists globally, with top 20 countries at 48% of per‑capita usage.
