Creative Work Is About to Look a Lot More Like Programming

Unknown Weber Wong creative workflows, visual programming, AI tools, Flora, design systems
Read the source article

Quick summary

Weber Wong argues that the real AI disruption in creative work is shifting from one‑off artifacts to reusable workflows—turning creativity into visual programming.

Key takeaways

  • Generative AI accelerates output but still traps creators in “artifact thinking.”
  • The next leap is reusable, shareable workflows that encode creative process.
  • Competitive advantage moves from model access to workflow orchestration.
  • Visual programming—building systems on a canvas—scales creative intent.
  • Design’s evolution (e.g., Figma components) is a precedent for reusable creative systems.
