Is Claude Code going to cost $100/month? Probably not—it’s all very confusing

April 22, 2026 Simon Willison Anthropic, pricing, Claude Code, trust, developer tools
Read the source article

Quick summary

Anthropic briefly exposed a higher Claude Code price point, and the backlash showed how fragile trust is when key developer tools feel unpredictably repriced.

Key takeaways

  • Anthropic briefly showed Claude Code as a Max-plan feature, implying a jump from $20 to $100 per month for some users.
  • The company quickly reverted the public pricing page while saying a limited test was affecting a small subset of new signups.
  • The episode created confusion because public documentation changed before any clear formal communication appeared.
  • For users, pricing uncertainty can be as damaging as an actual price increase because it changes adoption risk.
  • The incident gives competitors like OpenAI an opening to position stability and transparency as product advantages.
