The Pulse: AI load breaks GitHub – why not other vendors?

2026-04-30 Gergely Orosz GitHub, reliability, AI load, outages, Copilot pricing, Anthropic, Mitchell Hashimoto, building block economy, open source
Read the source article

Quick summary

GitHub's reliability has collapsed to near-zero nines under 3.5x AI-driven load increases, while Anthropic simultaneously races to destroy developer goodwill through service degradation and pricing changes.

Key takeaways

  • GitHub's reliability dropped to 86% (zero nines) in April 2026, with a data integrity incident and multiple outages
  • GitHub leadership attributes the degradation to a 3.5x increase in service load, which may be self-inflicted by AI tooling
  • Open source contributor Mitchell Hashimoto (Ghostty creator) is quitting GitHub, calling it unsuitable for professional work
  • Anthropic has been silently nerfing Claude Code, banning companies, and implementing baffling price rises
  • GitHub Copilot pricing is shifting to API token-based billing with ~3x increases for Pro/Pro+ plans, making costs unpredictable
