  • Hyperframes is an open-source video rendering framework that lets you create, preview, and render HTML-based video compositions — with first-class support for AI agents.
  • Quick Start Option 1: With an AI coding agent (recommended) Install the HyperFrames skills, then describe the video you want: npx skills add heygen-com/hyperframes This teaches your agent (Claude Code, Cursor, Gemini CLI, Codex) how to write correct compositions and GSAP animations.
  • In Claude Code, the skills register as slash commands — invoke /hyperframes to author compositions, /hyperframes-cli for CLI commands, and /gsap for animation help.
  • Try it: example prompts Copy any of these into your agent to get started.
