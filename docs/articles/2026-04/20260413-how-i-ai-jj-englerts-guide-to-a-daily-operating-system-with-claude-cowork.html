Quick summary

JJ Englert shows how Cowork becomes genuinely useful once you stop treating it like chat and start treating it like a persistent project space with a brain file, reusable skills, connectors, and scheduled tasks.

Key takeaways

  • JJ Englert shows how Cowork becomes genuinely useful once you stop treating it like chat and start treating it like a persistent project space with a brain file, reusable skills, connectors, and scheduled tasks.
  • JJ Englert’s workflow is a strong illustration of why project context beats repeated prompting. The key ingredient is a folder-backed project with a “brain” file that captures standing instructions, communication preferences, and recurring collaborators so the agent starts each task with durable context instead of a blank slate.
  • From there, Cowork becomes a skill builder rather than just a chat surface. JJ uses connectors to derive a personalized email-writing skill from sent messages, a multi-persona review skill for instant feedback, and recurring tasks like a morning debrief that scans email, Slack, and calendar before the workday starts.
  • The useful mental model is that personalized AI work is really about building a small internal operating system. Projects, examples, memory, and schedules are what make the outputs compound over time.
