OpenAI develops unified Codex app and new Scratchpad feature

April 13, 2026 TestingCatalog OpenAI, Codex, scratchpad, managed agents, desktop AI
Read the source article

Quick summary

OpenAI is reportedly building a Scratchpad that launches parallel Codex tasks from a todo-style UI while consolidating products around a broader Codex “superapp,” signaling that managed agent workflow is becoming the core UX battleground.

Key takeaways

  • OpenAI is reportedly building a Scratchpad that launches parallel Codex tasks from a todo-style UI while consolidating products around a broader Codex “superapp,” signaling that managed agent workflow is becoming the core UX battleground.
  • TestingCatalog describes an in-development Scratchpad interface for Codex that lets users create a todo list and spin up multiple coding chats in parallel. That design choice matters because it turns Codex from an answer engine into a work management surface: users specify a queue of outcomes and let agents execute against that queue concurrently.
  • The article also points to signs that OpenAI is converging its broader product portfolio into a single Codex-centered application. If accurate, that implies the company sees agent execution, rather than ordinary chat, as the organizing primitive for its desktop experience. The mention of heartbeat infrastructure reinforces that interpretation by suggesting support for long-running background tasks rather than isolated interactive turns.
  • The bigger takeaway is market convergence. Anthropic, OpenAI, and others are all circling the same idea: a persistent desktop agent environment with task queues, background execution, and tighter integration across research, chat, and coding. The fight is increasingly about operating system for agentic work, not just best model in a benchmark chart.
