Introducing Muse Spark: Meta's Most Powerful Model Yet

April 8, 2026 (updated May 12, 2026) Meta (press release) Meta, Muse Spark, LLM, Meta AI, Meta Superintelligence Labs, multimodal, agentic AI, personal superintelligence, open source
Read the source article

Quick summary

Meta unveiled Muse Spark, the first model from its new Meta Superintelligence Labs (MSL), a purpose-built multimodal LLM that powers a rebuilt Meta AI assistant across all Meta platforms, with ambitions toward "personal superintelligence" — an AI that understands your world because it's built on it.

Key takeaways

  • Muse Spark is the first release from Meta Superintelligence Labs, a nine-month ground-up rebuild of Meta's AI stack with a "deliberate and scientific approach to model scaling"
  • The model powers Meta AI with multimodal perception (vision + text), multiple subagents running in parallel, and separate "Instant" and "Thinking" modes for different task complexity
  • Key features include visual coding (websites/games from prompts), shopping mode across Marketplace and the web, and health advice developed with physician input
  • The May 12 update expanded access to WhatsApp, Instagram, Facebook, Messenger, and Ray-Ban/Oakley Meta glasses, with live AI camera features
  • Meta plans to offer API access to select partners and aims to open-source future versions of the Muse model series
