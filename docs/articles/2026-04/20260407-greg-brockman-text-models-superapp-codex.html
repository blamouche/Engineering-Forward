OpenAI President Greg Brockman: Doubling Down on Text Models, The Superapp Plan, Codex’s Potential

April 7, 2026 Big Technology OpenAI, Greg Brockman, superapp, Codex, GPT, personal assistant, AI strategy
Read the source article

Quick summary

Greg Brockman says OpenAI is concentrating on GPT-style models, a unified “superapp,” and broader computer-use workflows, arguing that one core model stack can power both personal assistance and serious work.

Key takeaways

  • Brockman says OpenAI is prioritizing GPT-style models over separate branches like standalone video generation.
  • OpenAI’s top application bets are a personal assistant and an AI that can solve hard work tasks with enough context and tools.
  • The company wants to unify chat, coding, browsing, and computer use into one endpoint application with shared memory and context.
  • Codex is being framed less as a tool for software engineers only and more as a general agent harness for computer-based work.
  • The interview suggests that harness design, context, tools, and memory now matter as much as the base model itself.
