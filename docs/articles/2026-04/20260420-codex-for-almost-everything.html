Codex for (almost) everything

April 20, 2026 OpenAI codex, computer use, plugins, memory, automations
Read the source article

Quick summary

OpenAI is expanding Codex from a coding assistant into a broader desktop work platform with computer use, browser control, image generation, memory, plugins, and long-running automations.

Key takeaways

  • Codex can now operate the computer directly with background computer use and multiple parallel agents.
  • The app adds an in-app browser, image generation, richer previews, PR review support, and SSH access to remote devboxes.
  • OpenAI is shipping more than 90 new plugins and integrations to extend Codex across common developer tools.
  • Automations and memory push Codex toward persistent, context-aware, long-running work rather than isolated prompts.
  • The release positions Codex as a unified workspace for moving across the full software development lifecycle.
