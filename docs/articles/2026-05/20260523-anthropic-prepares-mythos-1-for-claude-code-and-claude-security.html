Anthropic prepares Mythos 1 for Claude Code and Claude Security

May 23, 2026 Alexey Shabanov Anthropic, Mythos, Claude Code, cybersecurity, Claude Security, AI security, vulnerability discovery
Read the source article

Quick summary

Leaked UI strings and a Project Glasswing update indicate Anthropic is preparing "Mythos 1" for integration into Claude Code and Claude Security, marking a shift from restricted access toward broader availability of its cybersecurity-focused AI model — alongside a new vulnerability dashboard and rumors of Claude Opus 4.8.

Key takeaways

  • Project Glasswing, Anthropic's collaborative cybersecurity initiative, has found 10,000+ high- or critical-severity vulnerabilities since launch
  • Anthropic's public messaging shifted from "Mythos will remain restricted" to "we look forward to making Mythos-class models available through a general release once safeguards are in place"
  • UI leaks show a "claude-mythos-1-preview" model surfaced in Claude Code, with source code strings referencing "Access to the Claude Mythos model in Claude Code and Claude Security"
  • Claude Security is getting a refreshed dashboard with vulnerability discovery charts, seven-day and thirty-day history views, and triage results
  • Claude Opus 4.8 is rumored to be in internal evaluation with select partners, fitting the Opus 4.7 release cadence from April
  • Mythos traces have already appeared on Google Cloud and AWS through existing vulnerability discovery programs
