Chinese Grey Market Sells Claude API Access at 90% Off Through Proxy Networks That Harvest User Data

May 2026 Tom's Hardware Claude API, grey market, proxy networks, data harvesting, model substitution, stolen credentials, China
Read the source article

Quick summary

A Chinese grey market has emerged selling unauthorized Claude API access at 90% discounts through proxy networks that use stolen credentials, substitute models, and harvest users' prompts and outputs for resale as AI training data.

Key takeaways

  • Chinese-operated "transfer stations" offer Claude API access at up to 90% below official pricing through proxy networks
  • The grey market operates via stolen credentials and model substitution — users may not actually receive Claude responses but cheaper model outputs instead
  • Users' prompts and outputs are harvested and resold as AI training data, creating a double exploitation model
  • The operation exploits the gap between US export controls limiting official Claude/Anthropic API access in China and Chinese demand for frontier AI models
  • This represents a new vector for model security: not just protecting the model weights but preventing unauthorized API access and data exfiltration through proxy networks
  • The model substitution approach means users may be paying for Claude access but receiving responses from cheaper Chinese models — a quality risk compounded by data theft
