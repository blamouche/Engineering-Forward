Anthropic prepares Mythos 1 for Claude Code and Claude Security

May 23, 2026 Alexey Shabanov Anthropic, Claude, Mythos, cybersecurity, AI security, enterprise, Project Glasswing, Claude Code
Read the source article

Quick summary

Anthropic is preparing Mythos 1 for broader release through Claude Code and Claude Security, signaling a shift from restricted access to general availability once adequate safeguards are in place, alongside a new enterprise vulnerability dashboard and rumors of Claude Opus 4.8.

Key takeaways

  • Anthropic's Project Glasswing has found over 10,000 high- or critical-severity vulnerabilities in essential software since launch.
  • The company now states Mythos-class models could reach general release once "far stronger safeguards" are developed, a shift from earlier restricted-access framing.
  • Traces of "claude-mythos-1-preview" have surfaced on Google Cloud and AWS, with source code strings referencing access to "Claude Mythos model in Claude Code and Claude Security."
  • A new Claude Security dashboard is being built with vulnerability discovery data, 7-day and 30-day historical charts, and deeper triage results for enterprise customers.
  • Claude Opus 4.8 is rumored to be undergoing internal evaluations by select partners, with a potential launch in the coming weeks.
