Building a Growth Engine from Zero: How One COO Boosted ARR 38% Without a Growth Team Using Claude Code

May 11, 2026 Bessemer Venture Partners (Atlas Editors) Claude Code, AI growth engine, ARR growth, ICP analysis, paid acquisition, CRM attribution, no-code growth, startup go-to-market
Read the source article

Quick summary

Omar Ismail, COO of Ascend, built a complete AI-powered growth engine using Claude Code with zero dedicated growth hires, taking the company from $20M to $27.6M ARR (38% growth) in six months while achieving ~5x ROAS.

Key takeaways

  • Ascend went from 95% word-of-mouth revenue to a measurable, repeatable acquisition system entirely through Claude Code, connected to HubSpot, Meta, and LinkedIn APIs.
  • The three-stage process (ICP analysis → brand repositioning → execution stack) only works in order; skipping directly to paid ads without customer data foundations is the most common founder mistake.
  • Meta and LinkedIn require fundamentally different architectures: Meta is creative-led (algorithm finds the audience), LinkedIn is identity-led (precise targeting by job title, seniority, company type).
  • A 22-branch attribution rules engine built on HubSpot achieved near-100% contact attribution — answering "which channel brought in each paying customer and at what cost" changed every subsequent decision.
  • Claude Code slash commands like /daily-ad-review, /weekly-growth-report, and /new-campaign turned growth ops into a continuous compounding process rather than one-off projects.
