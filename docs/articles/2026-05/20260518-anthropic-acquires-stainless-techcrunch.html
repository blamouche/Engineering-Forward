Anthropic Has Acquired the Dev Tools Startup Used by OpenAI, Google, and Cloudflare

May 18, 2026 Kirsten Korosec (TechCrunch) Anthropic, Stainless, acquisition, SDK, developer tools, AI infrastructure, consolidation, Sequoia Capital, Andreessen Horowitz
Read the source article

Quick summary

Anthropic's acquisition of Stainless — the SDK-generation startup backed by Sequoia and a16z, used by OpenAI, Google, Replicate, Runway, and Cloudflare — takes a critical piece of shared AI developer infrastructure private and represents a consolidation play in the increasingly competitive AI platform wars.

Key takeaways

  • Deal reported at over $300 million, backed by Sequoia Capital and Andreessen Horowitz, with founder Alex Rattray (ex-Stripe) joining Anthropic
  • Stainless automates SDK generation from API specs across Python, TypeScript, Kotlin, Go, Java — automatically updating SDKs as APIs change, eliminating manual maintenance
  • Anthropic will wind down all hosted Stainless products; customers retain ownership of generated SDKs but lose the automated update service
  • The acquisition is strategically significant because AI agents increasingly depend on SDKs to connect to external software — controlling this layer gives Anthropic an agent connectivity advantage
  • This marks consolidation of shared AI developer infrastructure into platform-specific tooling, potentially forcing competitors to build in-house SDK tooling
