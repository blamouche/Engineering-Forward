How to Build a $20 Physical AI 'Buddy' with Claude Code

May 25, 2026 ChatPRD (from Felix Rieseberg interview) Claude Code, hardware, Bluetooth, physical AI, approval button, maker, DIY
Read the source article

Quick summary

A step-by-step guide to building a $20 physical AI companion using Claude Code: acquire a small LCD/Wi-Fi/Bluetooth device, describe the desired behavior in natural language, let Claude write all the low-level code, and connect it to Claude Desktop as a physical approval button.

Key takeaways

  • The hardware is a ~$19 self-contained device with LCD screen, Wi-Fi, and Bluetooth — no soldering or embedded systems knowledge required.
  • All code is generated by Claude Code from a natural language description: "I want my little Claude to live on this thing..."
  • Integration is through the Claude Desktop app's Developer Mode (Help > Troubleshooting > Enable Developer Mode).
  • The buddy lights up, makes sounds, and displays prompts when Claude needs permission — physically pressing the button grants approval.
  • The feature is now built into the Claude Desktop app for anyone to use, not just developers.
