Gas City

May 19, 2026 Gas Town Hall (Chris Sells, Julian Knutsen) Gas City, multi-agent orchestration, software factory, AI coding agents, Claude Code, Kubernetes for agents
Read the source article

Quick summary

Gas City is the successor to Steve Yegge's Gas Town — an open-source orchestration-builder SDK that extracts reusable multi-agent infrastructure into a configurable toolkit with declarative city configuration, multiple runtime providers, and Beads-backed work tracking.

Key takeaways

  • Gas City is an orchestration-builder SDK, not a monolithic tool: it provides composable infrastructure (runtime providers, work routing, health patrol) configured via city.toml.
  • Multiple runtime providers are supported: tmux, subprocess, exec, ACP, and Kubernetes — making it adaptable to different environments.
  • Built on Beads (a git-backed data plane) for work tracking, with formulas, molecules, waits, and mail for inter-agent communication.
  • A controller/supervisor loop reconciles desired state to running state, similar to Kubernetes architecture.
  • Has seen significant community adoption: 258 issues, 225 pull requests on GitHub.
  • Requires tmux, git, jq, and various CLI tools — with a quick brew install path for macOS users.
