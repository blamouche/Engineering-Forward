AI Work Is Splitting in Two

May 10, 2026 Every Staff (Context Window) AI agents, delegation, collaboration, Anthropic, OpenAI, Codex, Managed Agents, biotech, Code with Claude
Read the source article

Quick summary

AI work is bifurcating into two distinct modes — delegation to long-running autonomous agents and real-time collaboration with AI — and knowing which mode fits each task is becoming the critical meta-skill for knowledge workers.

Key takeaways

  • AI work is splitting into delegation (long-running agents like OpenClaw or Claude Managed Agents) and collaboration (desktop apps like Codex and Claude Code where humans and AI work side-by-side in real time).
  • Anthropic's 2026 Code with Claude conference centered on Managed Agents with new features for spinning up, scaling, and managing cloud-based Claude instances that run 24/7.
  • The "allocation economy" thesis — that the future is purely about delegating work to agents — only captures half the picture; collaborative AI work is equally important.
  • OpenAI's GPT-5.5 launch and Anthropic's developer conference happened back-to-back, signaling intensifying competition in the agent platform space.
  • Biotech R&D productivity is rising for the first time in years, driven by AI tools like AlphaFold and the collapse of genome sequencing costs to ~$200.
  • Anthropic announced a partnership to use SpaceX's Colossus supercluster, signaling the infrastructure scale required for agent platforms.
