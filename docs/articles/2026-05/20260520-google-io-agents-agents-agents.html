Google I/O: Agents, Agents, Agents

May 20, 2026 Jack Cheng Google I/O, agents, Gemini 3.5 Flash, agentic AI, AI Mode, collaborative agents, delegation agents, Stainless acquisition, MCP, Anthropic
Read the source article

Quick summary

Google I/O 2026 was a full-throated bet on agents as the primary product layer, with Gemini 3.5 Flash powering everything from a redesigned AI-native search to 24/7 personal agents that work while you sleep.

Key takeaways

  • Google is bifurcating its agent strategy into "collaborate with" agents (AI Mode search, Antigravity dev platform) and "delegate to" agents (Gemini Spark, Daily Brief, Universal Cart)
  • Gemini 3.5 Flash claims 4x faster speed at half the cost of comparable models, and is the engine powering most new agentic features
  • Anthropic acquired Stainless for a reported $300M — a developer tools company used by OpenAI and Google — to improve Claude's ability to connect to external tools and data via MCP
  • AI Mode is becoming the default search experience, with the ability to build custom mini-apps and interactive visualizations directly within search
  • Gemini Spark represents the always-on agent category: cloud-resident, multi-device, operating across Gmail, Docs, Chrome, and third-party tools
