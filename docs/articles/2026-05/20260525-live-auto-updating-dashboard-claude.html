How to Build a Live, Auto-Updating Personal Dashboard with Claude

May 25, 2026 ChatPRD (from Felix Rieseberg interview) Claude Cowork, Live Artifacts, dashboard, Connectors, Gmail, Spotify, Notion, Calendar, automation
Read the source article

Quick summary

A step-by-step guide to creating a personal dashboard that auto-refreshes with live data from Spotify, Gmail, Calendar, and Notion using Claude's Live Artifacts and Connectors — create it once, and it stays relevant forever.

Key takeaways

  • Set up Connectors in Claude settings to securely link Spotify, Gmail, Google Calendar, and Notion with OAuth-style sign-in, no API keys needed.
  • Use an open-ended prompt with the key phrase "make this a live artifact" to enable auto-refreshing capability.
  • Give Claude creative freedom: "whatever else you find that's relevant to my life" lets the model discover useful data sources.
  • Live Artifacts are a creative canvas — Felix demonstrated redesigning the dashboard as "early 2000s software" with Winamp references and pixelated aesthetics.
  • Once created, the dashboard refreshes with a single click, pulling the latest data from all connected services.
